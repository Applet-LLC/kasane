Emacs 風のキー操作の設定例

インストール先の samples\emacs\ に、Emacs の基本的なカーソル移動と編集、C-x で始まる操作、C-q（次のキーをそのまま送る）、Ctrl+Space のマークモードを、Windows の一般のアプリで使えるようにする設定が入っています。基本の設定は、レイヤー 3 枚、マクロ 36 件、キー置換 35 件です。トレイには依存しません。トレイが動いていなくても効きます。

動作は、内蔵キーボードで、Windows に届くキーの並びを見て確かめています（移動・編集の代表の操作、C-x の次の 1 キー、C-q の次の 1 キー、マークモード）。移動・編集の 32 件は、メモ帳でも確認しました。C-x の操作、C-q、マークモードの、アプリ上の実際の動きは、確かめていません。アプリによっては、期待どおりに動かないことがあります。

選択範囲を広げるには

Ctrl+Shift の組み合わせは、マークモードに入らずに、選択範囲を広げる方法です。Ctrl と Shift を押したまま、移動のキーを押すたびに、選択範囲が 1 つ分ずつ広がります。始点を置く操作は要りません。今いる位置が始点です。

例: 行の途中から、行末までを選ぶ。

  1. 選び始めたい位置にカーソルを置きます。
  2. Ctrl と Shift を押したまま、E を押します。カーソルから行末までが選ばれます。
  3. 範囲をそのまま切り取るなら、Shift を離し、Ctrl を押したまま W を押します。

例: 3 行下まで選ぶ。Ctrl と Shift を押したまま、N を 3 回押します。押しっぱなしにすると、オートリピートで広がり続けます。

  • 選択を始めるときも、続けるときも、操作は同じです。Ctrl と Shift の両方を押している間だけ、選択が広がります。
  • 途中で Shift を離して Ctrl+F などを押すと、選択は解除され、カーソルだけが動きます。
  • 選択をやめるときは、Shift なしの移動（Ctrl+F など）を使います。Ctrl+G は Esc を送るだけなので、アプリによっては選択が解除されません。
  • 単語単位で選ぶ操作（M-S-f など）は、入っていません。

C-x で始まる操作

Ctrl+X を押したあと、次に押す 1 キーだけが、別の割り当てになります。Ctrl を押したままでも、離してからでも、同じです（C-x C-s でも、C-x s でも、保存になります）。

押すキー 出るキー Emacs の操作
C-x C-s Ctrl+S 保存
C-x C-f Ctrl+O ファイルを開く
C-x C-w F12 名前を付けて保存（Word などの F12）
C-x b Ctrl+Tab 次のタブ（バッファの切り替え）
C-x k Ctrl+W タブを閉じる（バッファを消す）
C-x h Ctrl+A 全選択
C-x u Ctrl+Z 元に戻す
  • 上の表にないキーを C-x のあとに押すと、そのキーは普通に働きます（Ctrl を押していれば、Ctrl 付きのままです）。C-x の効果は、次の 1 キーで終わります。
  • C-x を続けて 2 回押すと、待ちは 1 回分のままです。
  • Windows の Ctrl+X（切り取り）は、C-x の前置きに変わります。切り取りは、C-w を使います。

C-q（次のキーをそのまま送る）

Ctrl+Q を押したあと、次に押す 1 キーだけは、Emacs 風の置き換えを受けずに、Ctrl 付きのキーとしてそのまま届きます。のどかの key C-Q = &Prefix(KeymapDefault) と同じ使い方です。たとえば C-q C-f は、→ ではなく、アプリへ Ctrl+F をそのまま送ります。

  • 対象は、A〜Z と Space です（C-q C-Space は、マークモードに入らず、Ctrl+Space を送ります）。それ以外のキーは、C-q のあとでも、普通の置き換えを受けます（C-/ が Ctrl+Z になるなど）。
  • C-q の効果は、次の 1 キーで終わります。もう一度 C-f を押せば、→ になります。
  • 仕組みは C-x と同じで、レイヤー 2 の各キーに、LCTL(KC_F) のような修飾付きキーを出すマクロを割り当てています。レイヤーに修飾付きキーを直接置くと、その出力が別の置き換えに当たってしまうためです。

マークモード（Ctrl+Space）

Ctrl+Space で、マークモードに入ります。入っている間は、移動のキー（←↑→↓、Home、End、PageUp、PageDown）に Shift が付き、移動のたびに選択範囲が広がります。Ctrl+F や Alt+F のように、移動のキーを出す割り当てにも、そのまま Shift が付きます。

マークモードの間に押すキー 出るキー
Ctrl+F / Ctrl+B / Ctrl+N / Ctrl+P Shift+→ / ← / ↓ / ↑
Ctrl+A / Ctrl+E Shift+Home / Shift+End
Ctrl+V / Alt+V Shift+PageDown / Shift+PageUp
Alt+F / Alt+B Ctrl+Shift+→ / ←
矢印キーなど、移動のキーそのもの Shift 付きの同じキー

マークモードは、移動のキーと修飾キー以外のキーを押すと、終わります。そのキーを送ったあとで終わるので、C-w（切り取り）や Alt+W（コピー）は、これまでどおり働いたあとにマークモードが終わります。

  • 終わるとき: C-w、Alt+W、Ctrl+G（Esc を送って終わります）、Enter、文字入力、BackSpace など。前面のウィンドウが変わったときも終わります（トレイが動いているとき）。
  • Ctrl+Space をもう一度押しても、マークモードは続きます。 選択範囲は変わりません（のどかと同じ動作です）。
  • マウスで選択範囲を変えても、マークモードは終わりません。 終わらせるには、移動以外のキーを 1 つ押します。
  • 範囲の始点は、移動を始めたときのカーソルの位置です。Ctrl+Space を押しても、見た目は変わりません。

書き込み方

コマンドラインから

管理者権限の PowerShell で、samples/emacs のフォルダに移動して実行します。<ID> は、KeymapTool --list で表示される 8 桁の 16 進数です。

PowerShell は、既定ではスクリプトの実行を許可していないことが多いので、-ExecutionPolicy RemoteSigned を付けて実行します。この指定は、このコマンドだけに効きます。

KeymapTool --list
PowerShell -ExecutionPolicy RemoteSigned .\apply-emacs.ps1 -Id <ID>

反映は、実行した直後からです。元に戻すときは -Remove を付けます。

PowerShell -ExecutionPolicy RemoteSigned .\apply-emacs.ps1 -Id <ID> -Remove

ダウンロードして展開したファイルは、Windows に「インターネットから取得した」と印を付けられ、RemoteSigned では実行を止められることがあります。その場合は、Unblock-File .\apply-emacs.ps1 を一度実行してから、もう一度試します。

KeymapTool の場所が違うときは -KeymapTool で指定します。

Ctrl+K を、Emacs と同じ動き（連続した切り取りの連結と、行末での改行の削除）にしたいときは、-KillLine を付けます。トレイが動いている必要があります。

PowerShell -ExecutionPolicy RemoteSigned .\apply-emacs.ps1 -Id <ID> -KillLine

詳しくは、後ろの「Ctrl+K を Emacs と同じ動きにする」を見てください。

ID ... のキーボードを、ドライバが認識していません と出る場合（KeymapTool 単体では Error: 1168）は、次を確かめます。

  • KeymapTool --list の表示に、その ID があるか。UniqId= の後ろの 8 桁を指定します。エディタや設定フォルダの名前にある ID と、同じとは限りません。
  • 表示が DeviceCount=0 のときは、ドライバがキーボードを認識していません。キーボードをつなぎ直すか、再起動してから、もう一度 --list を実行します。インストール直後は、ライセンスの有効化と再起動が済んでいるかも確かめます。
  • USB ポートを変えたり、Bluetooth を再ペアリングしたりすると、ID が変わります。そのときは、新しい ID を指定します。

エディタから

インポート／エクスポート... の インポート タブで、Emacs の設定例... を押します（インストールに同梱の samples\emacs\emacs.kasane.json が読み込まれます。ダウンロードしたファイルを使うときは、ファイルを選ぶ... で emacs.kasane.json を選びます）。読み込む項目は「レイヤー」「マクロ」「キー置換」の 3 つにし、読み込み方に 置き換え を選びます。キーボードの割り当てを確認してから読み込み、キーボードに適用(ON) を押します。この方法なら、設定が project.json に残るので、画面で内容を直せます。

注意点

  • キーボードのレイヤーマップを、置き換えます。 この設定は、A〜Z と Space の 27 キーだけのレイヤー 3 枚（0 が通常、1 が C-x、2 が C-q）を書き込みます。すでにレイヤーマップを設定しているキーボードでは、それが消えます。ほかのキーは、何も割り当てず、そのまま通ります。先にバックアップを取ってください。
  • キー置換は 0〜34 番、マクロは 92〜127 番を使います。 同じ番号を使っていた設定は、置き換わります。それ以外の番号は変わりません。-Remove は、レイヤーマップ全体と、この番号だけを消します。
  • コマンドラインで書き込んだ分は、エディタを使うときに消えることがあります。 エディタの キーボードに適用(ON) は、画面が持っている設定で置き換えます。コマンドラインで書き込んだあとに画面から適用するなら、先に上のインポートも済ませてください。
  • 全アプリに効きます。 Ctrl+F や Ctrl+S など、アプリ自身のショートカットは使えなくなります。本物の Emacs や、Emacs 風の操作を持つエディタでは、二重に働くことがあります。そのアプリが前面のときだけ止めたいときは、トレイのアプリ別レイヤーで、リマップをOFFにする 規則を作ります（11. ヘルパー動作とアプリ別レイヤー）。
  • Ctrl+K は、アプリによって動きが違います。 既定の設定では、Shift+End のあと Ctrl+X を送るだけです。行末で押したとき、メモ帳などは何も切り取りません。VS Code など、選択がないと行全体を切り取るアプリでは、行ごと消えます。Emacs のように、行末で改行を消す動きにはなりません。-KillLine を付けると、メモ帳などの一般的なアプリでは、Emacs と同じ動きになります（次の節）。
  • 割り当てはキーの位置（スキャンコード）で決まります。Alt+Shift+, と Alt+Shift+. は、どちらの配列でも、「<」と「>」を打つキーです。

Ctrl+K を Emacs と同じ動きにする

apply-emacs.ps1 に -KillLine を付けると、Ctrl+K が、トレイのヘルパー動作 KillLine になります（のどかの &EmacsEditKillLine と同じ作りです）。キーボードの helper.json に、動作を Id 100 で足します。ほかの動作は変えません。-Remove で、この動作も消えます。

動きは、次のとおりです。

  • 行末まで切り取り、切り取った分をクリップボードに入れます。
  • 続けて Ctrl+K を押すと、切り取った分が 1 つにつながります。Ctrl+Y（貼り付け）で、まとめて戻せます。
  • 行末で押すと、改行をつないで、Delete を送ります（次の行が上がってきます）。
  • つなぐのをやめるのは、Ctrl+K 以外のキーを押したとき、前面のウィンドウが変わったとき、クリップボードに別の内容が入ったとき、60 秒たったときです。

注意点です。

  • トレイが動いている必要があります。 止まっていると、Ctrl+K は何も出しません。
  • VS Code などでは、そのままでは合いません。 選択がないと行全体を切り取るアプリや、改行の扱いが違うアプリでは、動きがずれます。メモ帳などの一般的なアプリで確かめています。アプリごとに動きを変える対応は、これからです。
  • 最初に使ったときから、トレイが、実際のキー入力を見張ります（Ctrl+K 以外のキーが押されたかを知るためです）。キーの内容は記録しません。

入っていないもの

マークモードの、Emacs との違い

Emacs のように、マークの位置を持つわけではないので、次の点が違います。

  • Ctrl+Space をもう一度押しても、マークの位置は置き直されません（のどかと同じです）。
  • マークの位置に戻る操作（C-x C-x）はありません。
  • マウスの操作では終わりません。

C-x のそのほかの操作

C-x C-c（終了）、ウィンドウの分割や切り替え（C-x 0、1、2、3、o）、矩形（C-x r …）、C-x C-x は入っていません。C-x のあとのキーは、レイヤー 1 に、MACRO(n) として足せます（LCTL(KC_S) のような修飾付きキーをレイヤー 1 に置くと、その出力が、Ctrl+S の置き換え（検索）に当たってしまうためです）。

そのほか

キルリング（切り取りの履歴を C-y のあとに M-y でたどる操作）、矩形選択、C-u の繰り返し指定、のどかの &Emacs* 関数は、再現できません。
