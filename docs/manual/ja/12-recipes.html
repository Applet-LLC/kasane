12. 設定の例

よくある設定を、手順つきで紹介します。キーの割り当ての画面や、各エディタの使い方は、8. キーの割り当てと9. マクロ・コンボ・タップダンス・キー置換で説明しています。

キーを割り当てる手順

  1. エディタで、設定するキーボードとレイアウトを選びます（5. エディタの基本画面）。
  2. キー図のキーをクリックして、「キーの割り当て」の画面を開きます。
  3. 左の一覧から選んで割り当てるか、画面の下の キーコード 欄に、例に書いたキーコードを、そのまま入力して、OK を押します。
  4. 設定が終わったら、キーボードに適用(ON) を押します（管理者として起動していること）。

この章のキーコードは、キーコード 欄に書いてかまいません。キーの名前は、キー図の上のキーを押して、確かめられます。

別のレイヤーのキーを設定するときは、画面上部のレイヤーの一覧で、レイヤーの番号を選んでから、キーをクリックします。レイヤーを増やすときは、＋ 追加 を押します。

例 1: Caps Lock と左 Ctrl を入れ替える

キー 割り当てるキーコード
Caps Lock（JIS では、英数キー） KC_LCTRL
左 Ctrl KC_CAPSLOCK

詳しい手順は、5. エディタの基本画面の「キーを入れ替える」にあります。

例 2: Caps Lock を、短く押すと Esc、長押しすると Ctrl にする

Mod-Tap を使います。

キー 割り当てるキーコード
Caps Lock MT(MOD_LCTL,KC_ESC)

「キーの割り当て」の画面では、左の一覧の Mod-Tap (MT) を選び、修飾キーに左 Ctrl、タップのキーに KC_ESC を指定して、キーコード欄に入れる を押します。

  • 短く押して離すと、Esc になります。
  • 押したまま別のキーを押すと、Ctrl を押した状態になります。たとえば、Caps Lock を押しながら C を押すと、Ctrl+C です。
  • 速く打つと、意図せず長押しになるときは、設定ダイアログの「タイミング」タブで、判定方式を変えます（13. 設定ダイアログ）。

例 3: Space を押したまま、Shift として使う

キー 割り当てるキーコード
Space MT(MOD_LSFT,KC_SPC)

短く押すと Space、押したまま別のキーを押すと、Shift を押した状態になります。

例 4: Space を押したまま、H、J、K、L で矢印キーを打つ

Layer-Tap を使って、Space を押している間だけ、別の配置（レイヤー 1）にします。

  1. ＋ 追加 で、レイヤー 1 を作ります。
  2. レイヤー 0 の Space に、LT(1,KC_SPC) を割り当てます。「キーの割り当て」の画面の Layer-Tap (LT) で、レイヤーに 1、タップのキーに KC_SPC を指定してもかまいません。
  3. レイヤー 1 を選んで、次のキーを割り当てます。
キー 割り当てるキーコード
H KC_LEFT
J KC_DOWN
K KC_UP
L KC_RIGHT

レイヤー 1 の、ほかのキーは、▽（透過）のままにします。Space を押している間も、ほかのキーは、普段どおり動きます。

例 5: Caps Lock を無効にする

キー 割り当てるキーコード
Caps Lock KC_NO

基本 カテゴリの KC_NO（✕）を選んでも、同じです。

例 6: Caps Lock で IME をオン・オフする

Caps Lock を、日本語入力（IME）のオンとオフを切り替えるキーにします。Alt+半角/全角は、JIS 配列と US 配列のどちらのキーボードでも、Microsoft IME のオンとオフが切り替わる組み合わせです。

キー 割り当てるキーコード
Caps Lock LALT(KC_ZKHK)

KC_ZKHK は、半角/全角キーです。NLS カテゴリの 半/全 を選び、修飾キーの 左Alt にチェックを付けても、同じ割り当てになります。

あるキーで IME をオン、別のキーでオフにしたいときは、NLS カテゴリの IMEオン（KC_LNG1）と IMEオフ（KC_LNG2）を割り当てます。IME の設定は変えなくてかまいません。すでにオンのときに IMEオン を押しても、オンのままです（8. キーの割り当て）。

Microsoft IME の「キーとタッチのカスタマイズ」で、変換に IME-オン、無変換に IME-オフを割り当てている場合は、変換（KC_HENK）と無変換（KC_MHEN）を割り当てても同じように使えます。この割り当てをしないまま変換を押すと、IME は再変換として扱います。

Shift+Caps Lock で、本来の Caps Lock にする

Caps Lock のキーに LALT(KC_ZKHK) を割り当てると、Shift を押しながらでも、同じ割り当てが働きます。Shift+Caps Lock を、本来の Caps Lock として使いたいときは、キー置換を足します。

  1. エディタの画面下の キー置換... を開き、次のように入力して、OK を押します。
項目 入力
修飾キー MOD_LSFT
キー KC_ZKHK
置き換え先 LSFT(KC_CAPSLOCK)
  1. 設定... の「機能」タブで、キー置換が ON になっていることを確かめます。
  2. キーボードに適用(ON) を押します。
  • キー には、キー置換の対象になる、出力のキーを書きます。Caps Lock に割り当てた LALT(KC_ZKHK) の、キーの部分(KC_ZKHK)です。
  • 置き換え先 は、JIS 配列の Windows では LSFT(KC_CAPSLOCK) にします。JIS 配列では、Shift を押さない Caps Lock のキーは「英数」キーとして働き、Caps Lock が切り替わるのは、Shift を押しているときだけだからです。US 配列の Windows では、KC_CAPSLOCK で足ります。

これで、次のように動きます。

  • Caps Lock だけを押すと、IME のオンとオフが切り替わります。
  • Shift を押しながら Caps Lock を押すと、Caps Lock が切り替わります。

キー置換は、出力のキーで対象を決めます。そのため、本物の半角/全角キーを Shift と一緒に押したときも、Caps Lock に置き換わります。

例 7: 右 Alt を、左 Ctrl と左 Alt の同時押し（AltGr）にする

キー 割り当てるキーコード
右 Alt LCTL(KC_LALT)

右 Alt を押すと、左 Ctrl と左 Alt を同時に押した状態になります。AltGr のあるキーボード配列（ドイツ語など）の Windows では、AltGr で入力する文字が出ます。AltGr のない配列（米国、日本、韓国）では、Ctrl+Alt のショートカットとして働きます。

反対に、右 Alt が、意図せず AltGr（左 Ctrl と左 Alt の同時押し）になって困るときは、16. トラブル対応、既知の制限などのトラブル対応を見てください。

例 8: Shift+2 で " が出るようにする

US 配列のキーボードを、US 配列の Windows で使っていて、Shift+2 で @ が出るのを、" に変える例です。キー置換を使います。

  1. キーボードのレイアウトを、US104 にします。
  2. エディタの画面下の キー置換... を開きます。
  3. 次のように入力して、OK を押します。
項目 入力
修飾キー MOD_LSFT
キー KC_2
置き換え先 LSFT(KC_QUOTE)
  1. 設定... の「機能」タブで、キー置換が ON になっていることを確かめます。
  2. キーボードに適用(ON) を押します。

置き換え先には、Shift を掛けたアポストロフィのキー（LSFT(KC_QUOTE)）を書きます。置き換えているあいだ、条件の Shift は一時的に離されるので、置き換え先に Shift を書かないと、' が出ます。

反対に、US 配列のキーボードを、JIS 配列の Windows で使っている場合は、Shift+2 で " が出ます。@ を出したいときは、置き換え先に KC_LBRC を指定します（9. マクロ・コンボ・タップダンス・キー置換の「キー置換」）。

例 9: Shift+BS を Delete にする

項目 入力
修飾キー MOD_LSFT
キー KC_BSPACE
置き換え先 KC_DELETE

手順は、例 8 と同じです。

例 10: Ctrl+1 で、キーの並び（マクロ）を出す

例として、全選択してコピーする（Ctrl+A、Ctrl+C）マクロを、Ctrl+1 で出します。マクロとキー置換を使います。

  1. エディタの画面下の マクロ... を開きます。
  2. マクロ 0 の中身に、次のように入力します（キーをスペースで区切ります）。
LCTL(KC_A) LCTL(KC_C)
  1. OK を押します。
  2. キー置換... を開き、次のように入力して、OK を押します。
項目 入力
修飾キー MOD_LCTL
キー KC_1
置き換え先 MACRO(0)
  1. 設定... の「機能」タブで、マクロとキー置換が ON になっていることを確かめます。
  2. キーボードに適用(ON) を押します。

Ctrl+1 を押すと、マクロ 0 が 1 回実行されます。Ctrl+1 そのものは、アプリに届きません。実行の間だけ、押している Ctrl が離されるので、マクロの中で Ctrl を使うキーは、LCTL(KC_A) のように書きます。

文字列や待ちを含む手順を出したいときは、ヘルパー動作のトリガーを使います（11. ヘルパー動作とアプリ別レイヤー）。

例 11: テンキーを、押すたびに切り替わる 3 つの配置にする

テンキー単体のキーボードを、0 キーで、レイヤー 0 → 1 → 2 → 0 と切り替えます。

  • レイヤー 1: 一部のキーを、ショートカットと修飾キーにする。
  • レイヤー 2: 1〜9 のキーで、決まった文字列を入力する。

準備

  1. テンキーのキーボードを選び、レイアウトを 10KEY にします。
  2. ＋ 追加 を 2 回押して、レイヤー 1 と 2 を作ります。

レイヤーを切り替える

TO(n) は、レイヤー n だけを有効にします。3 つのレイヤーの 0 キーに、次のレイヤーへ進む TO(n) を割り当てると、押すたびに、0 → 1 → 2 → 0 と進みます。

レイヤー 0 キー
0 TO(1)
1 TO(2)
2 TO(0)

「キーの割り当て」の画面では、レイヤー操作 の 種類 で TO を選び、レイヤー に番号を指定して、キーコード欄に入れる を押します。

レイヤー 1 の割り当て

レイヤー 1 の 0 キーは、切り替えに使うので、左 Shift は、+ キーに割り当てます。

キー 出すもの キーコード（US 配列の Windows） キーコード（JIS 配列の Windows）
4 Ctrl+] LCTL(KC_RBRACKET) LCTL(KC_BSLASH)
1 Ctrl+[ LCTL(KC_LBRACKET) LCTL(KC_RBRACKET)
5 Ctrl+Shift+P LCTL(LSFT(KC_P)) 同じ
2 Ctrl+Shift+O LCTL(LSFT(KC_O)) 同じ
+ 左 Shift KC_LSHIFT 同じ
. 左 Ctrl KC_LCTRL 同じ
Enter 左 Alt KC_LALT 同じ
0 レイヤー 2 へ TO(2) 同じ

[ と ] のキーコードが、配列で違うのは、キーコードが、キーの位置（スキャンコード）を表すためです。Windows の配列が JIS のときは、] のキーが KC_BSLASH、[ のキーが KC_RBRACKET です。

レイヤー 2 の割り当て

1〜9 のキーに、ヘルパー動作の「文字列を入力する (Text)」を割り当てます。0 キーは、レイヤー 0 に戻ります。

キー 割り当て
1〜9 ヘルパー動作（文字列を入力する）。例: 1 は「お世話になっております。」、2 は「よろしくお願いいたします。」
0 TO(0)
  1. レイヤー 2 を選び、1 のキーをクリックします。
  2. 左の一覧から ヘルパー動作 を選び、新しい動作... を押します。
  3. 種類を 文字列を入力する (Text) にして、入力する文字列を書き、OK を押します。キーには、HLP(1) のようなコードが入ります。
  4. 2〜9 のキーも、同じようにします。

ヘルパー動作は、トレイが動いているときだけ働きます（11. ヘルパー動作とアプリ別レイヤー）。

適用して確かめる

キーボードに適用(ON) を押します。メモ帳を開いて、次のように確かめます。

  1. 0 キーを押す。レイヤー 1 になる（トレイのアイコンに、レイヤーの番号 1 が出ます）。
  2. 4 を押して、Ctrl+] が働くかを確かめる。+ を押しながら、別のキーを押すと、Shift を押した状態になる。
  3. 0 キーを押す。レイヤー 2 になる。1〜9 で、設定した文字列が入力される。
  4. 0 キーを押す。レイヤー 0 に戻る。

トレイのメニューの レイヤー からも、レイヤーを切り替えられます（4. トレイ）。
