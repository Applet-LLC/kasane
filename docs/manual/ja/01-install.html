1. インストール

kasane のインストーラーは、キーボードドライバ（kbdlayer）、ライセンス管理サービス、エディタ（kasane）、トレイ（常駐アプリ）をまとめて入れます。インストール先は C:\Program Files\applet\kasane に固定されていて、変更できません。

この章は Subscription 版の手順で書いています。買い切り版（Pro）の違いは「Pro 版のインストール」に、Subscription 版からの移行は「Subscription 版から Pro 版へ移る」にまとめました。

準備するもの

  • Windows 11 25H2（x64 または ARM64）
  • 管理者権限のあるアカウント
  • ダウンロードした kasane-subscription_1.00.zip（Pro 版は kasane-pro_1.00.zip）。Gumroad のライブラリから、いつでも再ダウンロードできます

zip を展開すると、次のファイルが入っています。

ファイル 内容
Install-kasane.exe インストールの起動画面。ここから始めます
KasaneSetup-ja-JP.msi, KasaneSetup-en-US.msi 言語別のインストーラー本体。Install-kasane.exe が自動で選びます
License.ja-JP.rtf, License.en-US.rtf 使用許諾
README.ja-JP.txt, README.en-US.txt インストールガイド
THIRD-PARTY-NOTICES.txt, third-party フォルダ 第三者のソフトウェアの一覧と、ライセンスの全文

Install-kasane.exe と .msi は、同じフォルダに置いたまま実行してください。

手順

1. Install-kasane.exe を実行する

Install-kasane.exe を実行します。Windows の言語が日本語なら日本語で、それ以外なら英語で表示されます。右上のリンクで切り替えられます。

説明文のとおり、ライセンスキーの入力はインストール後に出る License Manager で行います（3. ライセンスの認証）。インストール を押すと、インストーラーが始まります。同じフォルダに .msi が見つからないときは、画面に赤字で表示され、ボタンが押せなくなります。

2. セットアップウィザードに従う

ウィザードは次の順に進みます。

  1. ようこそ
  2. 使用許諾契約書: 内容を確かめて、使用許諾契約書に同意します(A) にチェックを入れます。
  3. 機能の選択: 6 つの機能（ドライバ、トレイ、ライセンスサービス、ライセンス管理、エディタ、共通ファイル）がすべて必須です。選び直しはできません。
  4. 設定フォルダの指定
  5. 設定ファイルの取り込み
  6. インストールの準備完了、進行
  7. 完了

設定フォルダの指定

設定ファイル（キーボードごとの設定、トレイの設定、ログ）の保存先を指定します。環境変数 KASANE として、マシン全体に設定されます。

  • 空欄のままにすると、各ユーザーの %LOCALAPPDATA%\applet\kasane に保存されます。
  • 指定するときは、D:\kasane のように、ドライブ文字から始まるフルパスにします。エクスプローラーでコピーしたパスのように、前後に " が付いていても、インストーラーが外します。
  • 指定したフォルダが無ければ、インストーラーが作ります。すでにあるフォルダの権限は変えません。
  • 設定フォルダを同じ場所に指定しても、i8042prt の設定は戻りません。ドライバに保存されていて、アンインストールで消えるためです。残したいときは、アンインストールの前に、復旧用の設定を含めてエクスポートしてください（2. アンインストール）。
  • 管理者保護（Windows 11 の機能）を使っているときは、ここで指定してください。昇格したエディタと通常のトレイが、同じフォルダを見るようになります。書き込めないときの直し方は、15. バックアップと移行を見てください。

後から変える場合は、インストーラーをもう一度実行します（13. 設定ダイアログの「保存先」タブには、現在の値が表示されます）。変更した後は、必要に応じて、再起動、またはサインアウトとサインインをしてください。

設定ファイルの取り込み

以前の環境から書き出した設定ファイル（*.kasane.json）を、インストール時にドライバへ反映します。既定ではオフです。

  1. 設定ファイルを取り込む にチェックを入れます。
  2. 設定ファイルのフルパスを入力します。この欄は右クリックが使えないので、キーボードで Ctrl+V を押して貼り付けます。
  3. 次へ を押したときに、ファイルが無ければ、「設定ファイルが見つかりません」という確認の画面が出ます。パスを直すか、「設定ファイルを取り込む」のチェックを外してください。

新規にインストールするとき、設定フォルダ（前の画面で指定したフォルダ）に kasane-recovery.kasane.json があれば、このファイルが自動で選ばれ、設定ファイルを取り込む にチェックが入った状態で表示されます。不要なら、チェックを外してください。このファイルは、エクスポートで 復旧用の設定も含める を選ぶと、設定フォルダに作られます（14. インポート／エクスポート）。画面を出さないインストールでも、KASANE_DIR で指定した設定フォルダに同じファイルが見つかれば取り込みます。止めるときは、「サイレントインストール」の項を参照して、IMPORT_SETTINGS=0 を渡してください。kasane がすでに入っている状態での上書きインストール（更新や修復）では、ファイルを探さないので、自動では選ばれません。設定はそのまま残っており、古いファイルで置き換えてしまうのを避けるためです。取り込みたいときは、設定ファイルを取り込む にチェックを入れて、ファイルのパスを入力してください。

復旧用の設定が入ったファイルを取り込むと、緊急解除の組み合わせ、i8042prt の設定、キーボードごとの共有範囲も、ドライバへ戻ります。トレイの設定（色、言語、デスクトップのアイコンの表示方法など）と、自分で追加したレイアウトは、トレイが最初に起動したときに、まだ無いものだけが戻ります。

取り込んだ設定は、再起動後（またはキーボードを接続し直したとき）から有効になります。すでに設定のある型番は置き換わり、前の設定は 1 世代だけ退避されます。退避した設定は、設定ダイアログの「保存先」タブから戻せます（14. インポート／エクスポート）。結果は %ProgramData%\applet\kasane\import.log に残ります。

3. インストールを実行する

インストール を押すと、ファイルのコピーと登録が始まります。ここまでの設定を確かめたいときは、戻る で前のページに戻れます。

インストールは、数分以内に終わります。

4. 再起動する

インストールが終わると、完了の画面に再起動を促すメッセージが出ます。

再起動後にログインすると、License Manager が一度だけ自動で開きます。トレイのアイコンも、タスクトレイに表示されます。再起動の前は、ドライバが停止したままなので、リマップは効きません。

5. ライセンスを認証して、もう一度再起動する

License Manager でライセンスキーを入力し、アクティベートします（3. ライセンスの認証）。そのあと、もう一度再起動するか、キーボードを接続し直すと、使えるようになります。

入るもの

項目 内容
スタートメニュー applet フォルダの中の かさね Subscription フォルダに、「かさね」（エディタ）、「かさね Tray」、「kasane License Manager」の 3 つ（英語版のインストーラーでは、「kasane」など英語の名前）
自動起動 トレイが、ログオン時に自動起動します。管理者保護を使っているときは、UAC の確認が出ないよう、タスクスケジューラのタスクで起動します（4. トレイ）
サービス ライセンス管理サービス kasaneLicenseSvc（自動起動）
ドライバ キーボードクラスフィルタドライバ kbdlayer（再起動後に有効）

上書きインストール

新しい版は、そのまま上書きインストールできます。アンインストールは要りません。ドライバの設定もライセンスも、引き継がれます。

上書き、アンインストール、修復の前には、インストーラーがトレイを自動で止めます。

Pro 版のインストール

Pro 版は、kasane-pro_1.00.zip を展開して入れます。手順は Subscription 版とほぼ同じで、次の点が違います。

項目 Pro 版
起動画面 Install-kasane-pro.exe。画面にライセンスキーの入力欄があります
インストーラー本体 KasaneProSetup-ja-JP.msi、KasaneProSetup-en-US.msi。.msi を単独で起動してもインストールできます。上書きインストールでは、ライセンスキーを入れずにインストールできます。ただし、ライセンスキーの情報が残っていないときは、.msi を単独で起動した場合でも、ライセンスキーの入力が必要です
ライセンスキー 入力欄に貼り付けて インストール を押すと、インストーラーが Gumroad に 1 回だけ確認します（3. ライセンスの認証）
機能の選択 License Manager とライセンスサービスは入りません
再起動後 License Manager は開きません。再起動すれば、そのまま使えます
スタートメニュー applet フォルダの中の かさね Pro フォルダ
サービス ライセンス管理サービスは入りません

Subscription 版と Pro 版は、同じパソコンに両方入れられません。Subscription 版が入っているパソコンで Pro 版のインストールを始めると、案内が出て、先に進めません。

Subscription 版から Pro 版へ移る

上書きインストールはできません。次の順で、いったんアンインストールしてから入れ直します。

  1. 設定を残したいときは、kasane の設定をエクスポートします（14. インポート／エクスポート）。
  2. Subscription 版をアンインストールして、再起動します（2. アンインストール）。
  3. Install-kasane-pro.exe を実行し、Pro 版のライセンスキーを入力してインストールします。
  4. 再起動します。

アンインストールのあとに再起動しないまま Pro 版を入れると、ドライバの削除が終わっておらず、エラー（1722）で取りやめになることがあります。そのときは、再起動してからもう一度実行してください。再起動しても同じエラーになるときは、ライセンスキーを確認できていない可能性があります（うまくいかないとき）。

キーボードごとの設定（project.json）や、トレイの設定は、そのまま引き継がれます。Subscription 版のライセンスの記録（%ProgramData%\kbdlayer-license）は、Pro 版のインストール時に削除されます。Pro 版では使わないからです。

サイレントインストール

msiexec で、画面を出さずにインストールできます。設定フォルダと設定ファイルの取り込みは、次のプロパティで渡します。

プロパティ 意味 例
KASANE_DIR 設定フォルダ（環境変数 KASANE） KASANE_DIR=D:\kasane
IMPORT_SETTINGS 1 で、設定ファイルを取り込む。0 で、設定フォルダの復旧用のファイルの自動取り込みも止める IMPORT_SETTINGS=1
IMPORT_SETTINGS_FILE 取り込む設定ファイルのフルパス IMPORT_SETTINGS_FILE=C:\work\settings.kasane.json 
msiexec /i KasaneSetup-ja-JP.msi /qn KASANE_DIR=D:\kasane IMPORT_SETTINGS=1 IMPORT_SETTINGS_FILE=C:\work\settings.kasane.json

管理者保護が有効なときは、サイレントインストールでも、ログオンしているユーザーごとに、自動起動のタスクが作られます。誰もログオンしていないとき（たとえば、配布ツールがログオン前に実行したとき）は、タスクを作れないので、自動起動は Run キーのままになります。この場合、ログオンのたびに UAC の確認が出ます。使うユーザーがログオンした状態で、もう一度インストーラーを実行（修復）してください。

Pro 版では、LICENSEKEY にライセンスキーを渡します。サイレントインストールのログ（/l*v）には、キーの値は書かれません。

msiexec /i KasaneProSetup-ja-JP.msi /qn LICENSEKEY=XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX

うまくいかないとき

症状 原因と対処
「This is the wrong Windows version. It's for Windows 11.」と出て、進めない Windows 11 以外では、インストールできません
「再起動してから、もう一度」という趣旨のエラー（1722）で、巻き戻される 原因は 2 つあります。下の「エラー 1722 の原因」で切り分けてください
失敗したときのログを見たい %TEMP%\MSI*.LOG、%ProgramData%\kbdlayer-license\debug.log を確認してください

エラー 1722 の原因

エラー 1722 は、インストーラーが途中で呼んだプログラムが失敗したことを表します。kasane では、次の 2 つが原因になります。どちらでも、インストールは取りやめになり、パソコンは変更されません。

原因 当てはまる場面 対処
ドライバの削除が再起動待ちになっている 直前にアンインストールして、再起動していない コンピューターを再起動してから、もう一度インストールします
Pro 版のライセンスキーを確認できなかった Pro 版のインストール中。インターネットに接続していない、キーが違う、使用回数の上限を超えた、など 下の手順で理由を調べます

再起動したのに同じエラーが出るときは、2 つ目を疑ってください。Pro 版は、インストールの途中で Gumroad に 1 回だけキーを照会します。インターネットに接続できないと、この確認が失敗して、1722 になります。

理由は、次の順に確かめます。

  1. Install-kasane-pro.exe から始めたときは、失敗の理由が画面に出ます。画面の文言は 3. ライセンスの認証の「確認できなかったとき」の表で引けます。
  2. .msi を直接実行したときは、理由が画面に出ず、1722 だけが表示されます。この場合は、C:\Windows\Temp\kasane-pro-activator.log を開いてください。照会の経過と失敗の理由が残っています。
  3. ネットワークが原因だったときは、接続を確かめてから、Install-kasane-pro.exe をもう一度実行します。社内のネットワークなどで、Gumroad（gumroad.com）への通信が止められていないかも確認してください。

インターネットに接続できず、Gumroad に通信が届かなかったときは、キーの使用回数は増えません。接続を直したあとで、同じキーをそのまま入力できます。
