15. バックアップと移行

kasane の設定がどこに保存されているかと、バックアップ、別のパソコンやキーボードへの移行の方法を説明します。ファイルの細かい仕様は docs/SETTINGS-FILES.md にあります。

設定の置き場所は 3 つ

置き場所 入るもの 書き込むもの
ドライバのレジストリ 実際にキー入力に効いている設定の本体 キーボードに適用(ON) を押したとき（管理者権限が必要）
設定フォルダ エディタで編集する設定の元データ、トレイの設定 エディタ、トレイ
%ProgramData%\kbdlayer-license ライセンスのトークンと署名鍵 ライセンスサービス

キーを実際に入れ替えているのは、ドライバのレジストリの設定です。設定フォルダの project.json は、エディタで編集するための元データで、適用のたびにドライバへ書き込まれます。エディタに保存ボタンはありません。閉じるとき、別のキーボードに切り替えるとき、適用するときに、自動で保存されます。

ライセンスは、バックアップや持ち出しの対象ではありません。再インストールのあと、サービスが保存済みのキーで再確認します。

設定フォルダ

環境変数 KASANE に絶対パスがあればそのフォルダです。なければ %LOCALAPPDATA%\applet\kasane です。現在の場所は、設定ダイアログの「保存先」タブで確かめられます（13. 設定ダイアログ）。

ファイル 内容 バックアップ
<UniqId>\project.json キーボード 1 台分の設定（レイヤー、マクロ、コンボ、タップダンス、キー置換、タイミング、NICOLA、レイアウト名、実測したスキャンコード、つけた名前） 取る
<UniqId>\helper.json そのキーボードのヘルパー動作、トリガー、アプリ別レイヤー 取る
tray.json トレイの設定（IME連動、色のモード、表示言語など）と、全キーボード共通のヘルパー設定 取る
Layouts\kle-<名前>.json 「KLEから追加」で保存したレイアウト 取る。これが無いと、そのレイアウトを使う設定が開けません
backup\ インポートやクリアの前に、自動で作られるバックアップ 取っておくと安心です
tray-state.json ほか tray-*.json、tray.log トレイの状態の記録とログ 不要

<UniqId> は、キーボードごとの 8 桁の 16 進数です。同じキーボードでも、差し込む USB ポートを変えると変わります。ポートを元に戻せば、元の設定がそのまま使えます。

バックアップを取る

14. インポート／エクスポートの エクスポート で、範囲に 全体一括 を選びます。すべてのキーボードの設定とトレイの設定が、1 つの *.kasane.json に入ります。

エクスポートに入らないものは次のとおりです。

  • ライセンス
  • 自分で追加したレイアウトのファイル（Layouts\）
  • 緊急解除の組み合わせ（ドライバ全体の設定）
  • i8042prt の設定

同じ PC の同じキーボードに戻すだけなら、設定フォルダの <UniqId> フォルダ、tray.json、Layouts\ をコピーする方法でも構いません。

別のパソコン、別のキーボードへ移す

  1. 元のパソコンで、全体一括 をエクスポートします。
  2. 新しいパソコンに kasane をインストールし、キーボードを接続します。
  3. エディタの インポート／エクスポート... で、ファイルを読み込みます。ファイルの中のキーボードは、接続中のキーボードに自動で対応づけられます。UniqId が同じものを先に、次に HardwareId が同じものを割り当てます。合わないときは、画面で選べます。
  4. 配列の違うキーボード（JIS と US、テンキー付きなど）へ移すときは、意図しない割り当てになることがあります。読み込みの報告を確認してください。
  5. 実測値（キャリブレーションの結果）は、別の機器へ持ち越されません。必要なら、キャリブレーションをやり直してください。

インストール時に取り込む方法もあります（1. インストール）。

場面ごとの早見表

場面 すること
パソコンを買い替える 古いパソコンで全体一括をエクスポートし、新しいパソコンでインポートする。自分で追加したレイアウトがあれば、Layouts\ も一緒にコピーする
キーボードを買い替える 古いキーボードの設定を、新しいキーボードへインポートする。配列が違うときは、報告を確認して、キャリブレーションをやり直す
USB ポートを変えた エディタの設定とトレイの設定は引き継がれない。元のポートに戻すか、エクスポートとインポートで移す。ドライバの設定は、共有範囲が「同じ型番で共有」なら引き継がれる
再インストールする 上書きなら設定は残る。アンインストールすると、ドライバの設定は消える。先に全体一括をエクスポートしておく
設定を初期化する インポート／エクスポートの「クリア」タブを使う
管理者保護を使っている 昇格したエディタは別ユーザーで動くので、保存先が別になる。環境変数 KASANE で設定フォルダを固定する

管理者保護を使っているとき

Windows 11 の管理者保護が有効だと、昇格したエディタは別のユーザーとして動き、%LOCALAPPDATA% が通常の環境と別になります。環境変数 KASANE で設定フォルダを固定しておくと、昇格したエディタと通常のトレイが、同じ設定を見ます。

この機能の動作は、実機での確認が済んでいません。詳しい状況は docs/ADMIN-PROTECTION.md にあります。
