かさね ヘルプ

kasane（かさね）は、Windows のキーボードの割り当てを変えるツールです。キーの入れ替え、レイヤーの切り替え、長押しとタップで動作を変える Mod-Tap や Layer-Tap、マクロ、親指シフト（NICOLA）などを、キーボードごとに設定できます。

このヘルプは、画面の図を見ながら、インストールからアンインストールまでの全機能を説明します。

動作環境

  • Windows 11 25H2（x64 または ARM64）
  • インストールのための管理者権限
  • インターネット接続。Subscription 版では、ライセンス管理サービスが約24時間ごとにライセンスサーバー(Applet LLC が運営)へ接続し、サブスクリプションが有効かどうかを確認します。直近の確認結果を使うので、ネットワークに接続できなくても、最大7日間はオフラインのまま使えます。 Pro 版では、インストール時にライセンスキーを確認するときだけ必要です。

はじめての方へ

  1. インストールして、再起動します。
  2. ライセンスの認証をします（Pro 版は、インストール中に済んでいます）。
  3. エディタの基本画面で、キーボードを選び、キーを入れ替えて、キーボードに適用します。
  4. 困ったときのために、緊急解除とアンインストールの手順を先に見ておくと安心です。
