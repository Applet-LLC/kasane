18. README

インストール先の直下に、かさねの README があります。インストーラーの使い方、動作環境、インストール手順が書かれています。リンクをクリックすると、Windows の既定のアプリ（メモ帳など）で開きます。

ファイル 内容
README.ja-JP.txt 日本語の README です
README.en-US.txt 英語の README です

インストールの手順は、このヘルプの1. インストールにも、画面つきで載っています。

2026-11-10 1.01 キーの割り当て: 設定済みのキーを開くと、今の設定が入る。キーからコンボ・キー置換・タップダンスを作る・開く。IME オン/オフ（KC_LNG1 / KC_LNG2）を追加。ヘルパー動作に加えて、トリガーも選んで割り当てられる
マクロ・コンボ・タップダンス・キー置換: 削除・複製・並べ替えを追加。キー置換は 128 件まで。置き換え先にレイヤー操作とヘルパー動作を使える。修飾キーのチェックを追加
割り当ての一覧を文字で見る画面と、--dump-text を追加
Emacs 風の操作: マークモード（MARK）、ヘルパー動作 KillLine（C-k）、設定例の読み込み
ヘルパー動作: IME の切り替え方を選べる。トリガーに名前を付けられる
画面: 説明の文を減らし、「?」ボタンでヘルプの該当の節を開くようにした。状態の印（ドライバ、未適用、閲覧専用、編集中）、メッセージの種類、入力の誤りの印を追加。ダークテーマで、タブの中身が支援技術に出ない件を修正
ライセンス: 署名をサーバーに移した。送信する内容と、保存しないことを明記した
