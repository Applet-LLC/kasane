18. README、来歴

インストール先の直下に、かさねの README があります。インストーラーの使い方、動作環境、インストール手順が書かれています。リンクをクリックすると、Windows の既定のアプリ（メモ帳など）で開きます。

ファイル 内容
README.ja-JP.txt 日本語の README です
README.en-US.txt 英語の README です

インストールの手順は、このヘルプの1. インストールにも、画面つきで載っています。

来歴

2026-11-10 1.01

機能追加

  • Emacs風の操作を可能とする設定ファイルのインポート機能、マークモード（MARK）、KillLine（C-k）の実現
  • キー置換の数を 32 個から 128 個に変更
  • ヘルパー動作: IME ON/OFF 実施方法の選択の追加、トリガーに固有名の指定追加
  • 割り当てた設定を一覧表示するボタンおよび、CLI に --dump-text の追加

機能調整

  • キーごとの割り当て時に、そのキーの情報があらかじめ設定されるようにしました
  • マクロ、コンボ、タップダンス、キー置換において、削除、複製、並べ替えを追加
  • ダイアログから文言を削除し、ヘルプボタンの追加、ステータスインジケータの追加
  • ライセンス管理サーバーを別サーバーに移動。送信する内容と保存しないことを明記

不具合改修

  • マクロにおいて、物理的に押した修飾キーがマクロ実行後、離してしまう不具合解消
