20. Third-Party Notices

kasane includes things that come from software and data by other authors. Which ones are used, and under which licenses, is summarized in THIRD-PARTY-NOTICES.txt, directly under the installation folder. The full text of each license is in the third-party folder of the installation folder. When you click a link, it opens in the Windows default app.

List

File Contents
THIRD-PARTY-NOTICES.txt The list of the software used, with the source of each, where it is used, and the key points of its license

Full license texts

File Contents
dotnet-runtime-8.0.31-LICENSE.TXT The license of the Microsoft .NET runtime (MIT License)
dotnet-runtime-8.0.31-THIRD-PARTY-NOTICES.TXT The licenses of other software that the .NET runtime itself includes
dotnet-extensions-8.0.0-THIRD-PARTY-NOTICES.TXT The licenses of other software that the .NET extension libraries include
keyboard-layout-editor-LICENSE.md A note on how Keyboard Layout Editor layout data is treated
sirius-MIT-LICENSE.txt The license of Tenro (sirius) (MIT License). It is used by the feature that reads the IME state
wix-toolset-MS-RL-LICENSE.txt The license of the WiX Toolset, which builds the installer (Microsoft Reciprocal License)

The full text of the Eclipse Public License 2.0 for nodoka (nodoka4), and the BSD-3-Clause license for Mado Tsukai no Yuutsu (mayu) and YAMY, are included in THIRD-PARTY-NOTICES.txt.
