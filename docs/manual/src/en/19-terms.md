# 19. Terms of Use

The kasane license agreement is directly under the installation folder. It has the same content as the one shown on the installer screens. When you click a link, the text file (UTF-8) opens in the Windows default app (such as Notepad).

| File | Contents |
|---|---|
| [License.en-US.txt](../../License.en-US.txt) | The license agreement in English |
| [License.ja-JP.txt](../../License.ja-JP.txt) | The license agreement in Japanese |

The same content in RTF format (`License.en-US.rtf` and `License.ja-JP.rtf`) is also in the same folder.

The licenses of software by other authors that kasane includes are in [20. Third-Party Notices](20-third-party.html).
