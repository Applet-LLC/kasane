# 3. ライセンスの認証

kasane には、Gumroad のサブスクリプション版（Subscription）と、買い切り版（Pro）があります。ライセンスキーの扱いが違うので、この章に両方を書きます。

どちらの版を入れているかは、Windows の「インストールされているアプリ」に出る名前（「かさね Subscription」または「かさね Pro」）で分かります。

| | Subscription 版 | Pro 版 |
|---|---|---|
| ライセンスキーを入れる場面 | インストール後に、License Manager で入力する | インストールの途中で入力する |
| キーの確認 | ライセンスサービスが、約 24 時間ごとに Gumroad へ問い合わせる | インストール時に 1 回だけ問い合わせる |
| 解約・失効 | サブスクリプションが無効になると、リマップが止まる | 失効しない |
| License Manager、ライセンスサービス | 入る | 入らない |
| トレイの「ライセンス」 | ある | ない |

Pro 版は、インストールが済んだあとにインターネットへ接続する必要がありません。

## Subscription 版

kasane は、Gumroad のサブスクリプションに応じて機能が提供されます。インストールのあとは、License Manager でライセンスキーを入力し、アクティベートします。

### License Manager を開く

- インストール後の再起動で、ログインすると一度だけ自動で開きます。
- 後から開くときは、スタートメニューの `applet` フォルダにある **kasane License Manager** を選ぶか、トレイのアイコンを右クリックして **ライセンス** を選びます。

右上のリストで、表示言語を日本語と English から選べます。

### ライセンスキーを入力する

ライセンスキーは、Gumroad で購入したときのメールか、Gumroad のライブラリで確認できます。

![ライセンスキーの入力](../img/ja/license-input.png)

1. **ライセンスキー** の欄に、キーを貼り付けるか入力します。
2. **アクティベート** を押します。
3. 成功すると、キーの欄が読み取り専用の表示（途中を伏せたキー）に変わり、状態が「有効」になります。

![アクティベートが済んだ状態](../img/ja/license-activated.png)

購入していない場合は、画面の **Gumroad で購入する** のリンクから購入ページを開けます。

アクティベートのあと、もう一度再起動するか、キーボードを接続し直すと、リマップが使えるようになります。

### 画面の見方

| 項目 | 内容 |
|---|---|
| 状態 | 「有効(トークンの有効期限まで 6 日)」、「試用版(残り 5 日)」、「未アクティベート」、「アクティベート中...」など |
| 次回自動更新、試用期限 | サブスクリプションで、次に自動で再確認する日。試用版では、試用の期限 |
| ユーザー | 購入時に登録されたメールアドレス |
| **ライセンスを再確認** | Gumroad に問い合わせて、状態を取り直す |
| ライセンスキー(登録済み) | 登録したキー。途中が伏せられ、末尾の 4 文字だけが出る |
| 接続の診断 | 「サービス接続: OK」と「Gumroad 接続: OK(ライセンス有効)」など。アクティベートや再確認のあとに出る |

![接続の診断](../img/ja/license-diagnostics.png)

ライセンスサービスは、約 24 時間ごとに Gumroad へ接続して、サブスクリプションが有効かどうかを確認します。直近の確認結果を使うので、ネットワークに接続できなくても、最大 7 日間はオフラインのまま使えます。

### 試用版

試用ライセンスのキーを入れると、試用版として 6 日間使えます。画面には「試用版(残り 5 日)」と、試用の期限が出て、「6日間の試用版が有効になりました。」と表示されます。試用の期限が過ぎると、リマップは使えなくなります。

試用版は、Gumroad の無料のトライアル商品に照合して成立します。

![試用版の表示](../img/ja/license-trial.png)

### ライセンスが無効になったとき

サブスクリプションが無効になると、レイヤーのリマップの機能が使えなくなります。キーボードの基本的な入力は、そのまま使えます。

### エラーが出たとき

画面の赤字のメッセージで、原因が分かります。

| メッセージの種類 | 原因と対処 |
|---|---|
| 「ライセンスキーが無効です。Gumroad の購入内容を確認してください。」 | キーを入力し間違えているか、別の商品のキーです。Gumroad のライブラリで確かめます。画面には、Gumroad が返した詳細（例: `That license does not exist for the provided product.`）も出ます。このとき、状態の欄には、「アクティベート中...」が残ることがあります |
| ネットワーク、タイムアウト | インターネットに接続できません。接続を確かめて、**ライセンスを再確認** を押します |
| サーバーエラー、解析エラー | Gumroad 側の一時的な問題の可能性があります。しばらくしてから、もう一度試します |
| サービス未起動 | ライセンスサービス（`kasaneLicenseSvc`）が動いていません。再起動するか、Windows のサービスの画面で起動します |

![エラーの表示](../img/ja/license-error.png)

ログは `%ProgramData%\kbdlayer-license` の `debug.log` と `gui-debug.log` にあります。

## Pro 版

Pro 版のライセンスキーは、Gumroad の購入メールか、Gumroad のライブラリで確認できます。インストールの途中で入力すると、インストーラーが Gumroad に問い合わせ、有効なキーだけ先へ進みます。キーが無効だったときは、何もインストールされません。

### キーを入力する

`Install-kasane-pro.exe` を実行すると、最初の画面にキーの入力欄があります。キーを貼り付けて **インストール** を押します。この欄は右クリックでも貼り付けられます。

`.msi` を直接実行したときは、設定ファイルの取り込みの次に、キーの入力画面が出ます。この画面は右クリックが使えないので、キーボードで `Ctrl+V` を押して貼り付けてください。

サイレントインストールでは、`LICENSEKEY` で渡します（[1. インストール](01-install.html)の「サイレントインストール」）。

### 確認できなかったとき

`Install-kasane-pro.exe` から始めたときは、理由が画面に出ます。確認に失敗すると、インストールは取りやめになり、パソコンは変更されません。

| 画面の内容 | 原因と対処 |
|---|---|
| ライセンスキーが無効です | キーの入力ミスか、別の商品のキーです。Gumroad のライブラリで確かめます。返金やチャージバックのあったキーも、この表示になります |
| インターネットに接続できないため、確認できませんでした | 接続を確かめて、もう一度実行します。`.msi` を直接実行したときは、この理由が出ず、エラー 1722 だけが表示されます（[1. インストール](01-install.html)の「エラー 1722 の原因」） |
| 使用台数が上限を超えています | 1 つのキーで確認できる回数は 100 回までです。上限を超えたときは、Gumroad のサポートに連絡してください |

詳しい経過は、`C:\Windows\Temp\kasane-pro-activator.log` に残ります。

### 再インストールするとき

Pro 版を入れ直すときは、キーをもう一度入力します。確認のたびに、そのキーの使用回数が 1 つ増えます。新しい版への上書きインストールでは、キーは要りません。
