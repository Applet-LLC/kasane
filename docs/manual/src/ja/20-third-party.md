# 20. サードパーティノーティス

かさねには、他の作者のソフトウェアやデータに由来するものが含まれています。どれを、どのライセンスで使っているかは、インストール先の直下にある `THIRD-PARTY-NOTICES.txt` にまとめてあります。各ライセンスの全文は、インストール先の `third-party` フォルダに入っています。リンクをクリックすると、Windows の既定のアプリで開きます。
