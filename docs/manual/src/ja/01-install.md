# 1. インストール

kasane のインストーラーは、キーボードドライバ（kbdlayer）、ライセンス管理サービス、エディタ（kasane）、トレイ（常駐アプリ）をまとめて入れます。インストール先は `C:\Program Files\applet\kasane` に固定されていて、変更できません。

## 準備するもの

- Windows 11 25H2（x64 または ARM64）
- 管理者権限のあるアカウント
- ダウンロードした `kasane-subscription.zip`（Gumroad のライブラリから、いつでも再ダウンロードできます）

zip を展開すると、次のファイルが入っています。

| ファイル | 内容 |
|---|---|
| `Install-kasane.exe` | インストールの起動画面。ここから始めます |
| `KasaneSetup-ja-JP.msi`, `KasaneSetup-en-US.msi` | 言語別のインストーラー本体。`Install-kasane.exe` が自動で選びます |
| `License.ja-JP.rtf`, `License.en-US.rtf` | 使用許諾 |
| `README.ja-JP.txt`, `README.en-US.txt` | インストールガイド |
| `THIRD-PARTY-NOTICES.txt`, `third-party` フォルダ | 第三者のソフトウェアの一覧と、ライセンスの全文 |

`Install-kasane.exe` と `.msi` は、同じフォルダに置いたまま実行してください。

## 手順

### 1. Install-kasane.exe を実行する

`Install-kasane.exe` を実行します。Windows の言語が日本語なら日本語で、それ以外なら英語で表示されます。右上のリンクで切り替えられます。

![インストール起動画面](../img/ja/install-launcher.png)

説明文のとおり、ライセンスキーの入力はインストール後に出る License Manager で行います（[3. ライセンスの認証](03-license.html)）。**インストール** を押すと、インストーラーが始まります。同じフォルダに `.msi` が見つからないときは、画面に赤字で表示され、ボタンが押せなくなります。

### 2. セットアップウィザードに従う

ウィザードは次の順に進みます。

1. ようこそ
2. 使用許諾契約書: 内容を確かめて、同意にチェックを入れます。
3. 機能の選択: 6 つの機能（ドライバ、トレイ、ライセンスサービス、ライセンス管理、エディタ、共通ファイル）がすべて必須です。選び直しはできません。
4. 設定フォルダの指定
5. 設定ファイルの取り込み
6. インストールの準備完了、進行
7. 完了

![ウィザードの最初の画面](../img/ja/install-wizard-welcome.png)

#### 設定フォルダの指定

設定ファイル（キーボードごとの設定、トレイの設定、ログ）の保存先を指定します。環境変数 `KASANE` として、マシン全体に設定されます。

![設定フォルダの指定](../img/ja/install-wizard-datadir.png)

- 空欄のままにすると、各ユーザーの `%LOCALAPPDATA%\applet\kasane` に保存されます。ほとんどの場合は、空欄で構いません。
- 指定するときは、`D:\kasane` のように、ドライブ文字から始まるフルパスにします。
- 指定したフォルダが無ければ、インストーラーが作ります。すでにあるフォルダの権限は変えません。
- 管理者保護（Windows 11 の機能）を使っているときは、ここで指定すると便利です。昇格したエディタと通常のトレイが、同じフォルダを見るようになります。詳しくは[14. バックアップと移行](14-backup-migrate.html)を見てください。

後から変える場合は、インストーラーをもう一度実行します（[12. 設定ダイアログ](12-settings.html)の「保存先」タブには、現在の値が表示されます）。変更した後は、サインインし直してください。

#### 設定ファイルの取り込み

以前の環境から書き出した設定ファイル（`*.kasane.json`）を、インストール時にドライバへ反映します。既定ではオフです。

![設定ファイルの取り込み](../img/ja/install-wizard-import.png)

1. **設定ファイルを取り込む** にチェックを入れます。
2. 設定ファイルのフルパスを入力します。この欄は右クリックが使えないので、キーボードで `Ctrl+V` を押して貼り付けます。
3. **次へ** を押したときに、ファイルが無ければ、確認の画面が出ます。パスを直すか、チェックを外してください。

取り込んだ設定は、再起動後（またはキーボードを接続し直したとき）から有効になります。すでに設定のある型番は置き換わり、前の設定は 1 世代だけ退避されます。退避した設定は、設定ダイアログの「保存先」タブから戻せます（[13. インポート／エクスポート](13-import-export.html)）。結果は `%ProgramData%\applet\kasane\import.log` に残ります。

### 3. 再起動する

インストールが終わると、完了の画面に再起動を促すメッセージが出ます。

![完了の画面](../img/ja/install-wizard-finish.png)

再起動後にログインすると、License Manager が一度だけ自動で起動します。トレイのアイコンも、タスクトレイに表示されます。

### 4. ライセンスを認証して、もう一度再起動する

License Manager でライセンスキーを入力し、アクティベートします（[3. ライセンスの認証](03-license.html)）。そのあと、もう一度再起動するか、キーボードを接続し直すと、使えるようになります。

## 入るもの

| 項目 | 内容 |
|---|---|
| スタートメニュー | `applet` フォルダの中に、`kasane`（エディタ）、`kasane Tray`、`kasane License Manager` |
| 自動起動 | トレイが、ログオン時に全ユーザーで自動起動します |
| サービス | ライセンス管理サービス `kasaneLicenseSvc`（自動起動） |
| ドライバ | キーボードクラスフィルタドライバ `kbdlayer`（再起動後に有効） |

## 上書きインストール

新しい版は、そのまま上書きインストールできます。アンインストールは要りません。ドライバの設定もライセンスも、引き継がれます。

上書き、アンインストール、修復の前には、インストーラーがトレイを自動で止めます。

## サイレントインストール

`msiexec` で、画面を出さずにインストールできます。設定フォルダと設定ファイルの取り込みは、次のプロパティで渡します。

| プロパティ | 意味 | 例 |
|---|---|---|
| `KASANE_DIR` | 設定フォルダ（環境変数 `KASANE`） | `KASANE_DIR=D:\kasane` |
| `IMPORT_SETTINGS` | `1` で、設定ファイルを取り込む | `IMPORT_SETTINGS=1` |
| `IMPORT_SETTINGS_FILE` | 取り込む設定ファイルのフルパス | `IMPORT_SETTINGS_FILE=C:\work\settings.kasane.json` |

```
msiexec /i KasaneSetup-ja-JP.msi /qn KASANE_DIR=D:\kasane IMPORT_SETTINGS=1 IMPORT_SETTINGS_FILE=C:\work\settings.kasane.json
```

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「This is the wrong Windows version. It's for Windows 11.」と出て、進めない | Windows 11 以外では、インストールできません |
| 「再起動してから、もう一度」という趣旨のエラー（1722）で、巻き戻される | 直前にアンインストールしていて、ドライバの削除が再起動待ちになっています。コンピューターを再起動してから、もう一度インストールしてください |
| 失敗したときのログを見たい | `%TEMP%\MSI*.LOG`、`%ProgramData%\kbdlayer-license\debug.log` を確認してください |

![インストールに失敗したときの画面](../img/ja/install-launcher-failed.png)
