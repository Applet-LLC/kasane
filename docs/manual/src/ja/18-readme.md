## 来歴

### 2026-11-17 1.02

機能追加

- インストーラー: 設定フォルダの指定に「参照...」ボタンを追加（欄にパスがあるとき、環境変数 KASANE を設定済みのときは、そのフォルダを選んだ状態で開く）
- ヘルプの英語版を追加（表示言語が English のときは、英語版が開く）
- 使用許諾のテキスト版（License.ja-JP.txt、License.en-US.txt）を追加
- Emacs風の設定例に、C-q（次のキーをそのまま送る）を追加
- ThinkPad の日本語キーボードのレイアウト（THINKPAD_JP）を同梱

機能調整

- トレイのメニューの「設定」を「設定/エディタ」に変更
- エディタ下部のボタンの並びを「割り当ての一覧...」「設定...」の順に変更
- キー割り当ての画面などで、KC_RO（ろ）のキーの表示を「ろ」から「_」に変更
- インストーラー（Install-kasane.exe）を 2 つ同時に起動できないようにした
- ソースのライセンスが不統一だったので、ソースヘッダを Apache-2.0 に統一
- License Manager、ライセンスサービス、インストーラーなどのバージョンを 1.02 にそろえた

不具合改修

- Alt や Win を条件にしたキー置換のあと、Alt の単独押しが届き、メモ帳などでメニューバーが反応することがある不具合を解消（Issue #2）。ドライバが、戻した Alt・Win の直後に Ctrl のタップを挟む

### 2026-11-10 1.01

機能追加

- Emacs風の操作を可能とする設定ファイルのインポート機能、マークモード（MARK）、KillLine（C-k）の実現
- キー置換の数を 32 個から 128 個に変更
- ヘルパー動作: IME ON/OFF 実施方法の選択の追加、トリガーに固有名の指定追加
- 割り当てた設定を一覧表示するボタンおよび、CLI に `--dump-text` の追加

機能調整

- キーごとの割り当て時に、そのキーの情報があらかじめ設定されるようにしました
- マクロ、コンボ、タップダンス、キー置換において、削除、複製、並べ替えを追加
- ダイアログから文言を削除し、ヘルプボタンの追加、ステータスインジケータの追加
- ライセンス管理サーバーを別サーバーに移動。送信する内容と保存しないことを明記

不具合改修

- マクロにおいて、物理的に押した修飾キーがマクロ実行後、離してしまう不具合解消

### 2026-11-01 1.00

初版リリース。
