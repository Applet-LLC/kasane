# 2. アンインストール

kasane をパソコンから取り除く手順です。ドライバはキーボードで使用中のため、完全に削除されるのは再起動した時点です。

新しい版を入れ直すだけなら、アンインストールは要りません（[1. インストール](01-install.html)の「上書きインストール」）。

## 手順

### 1. リマップを OFF にする

kasane（エディタ）を開き、**OFF(素通しに戻す)** を押します。キーボードのリマップが止まり、キーが元の配置に戻ります。

![OFF(素通しに戻す)を押した状態](../img/ja/uninstall-off.png)

この手順を省くと、再起動するまでのあいだ、ドライバが動いたままになることがあります。手順 1 で OFF にしておけば、割り当ては効きません。

### 2. アプリと機能から削除する

Windows の設定の「アプリと機能」（「インストールされているアプリ」）で、「かさね Subscription」を探します。検索欄に「かさね」と入れると絞り込めます。右端の **…** を押すと、**変更** と **アンインストール** が出ます。**アンインストール** を選んでください。管理者の権限が必要です。

![Windows の設定でかさねを探す](../img/ja/uninstall-apps.png)

![… のメニュー](../img/ja/uninstall-apps-menu.png)

確認の画面が出たら、**はい** を押します。

![アンインストールの確認](../img/ja/uninstall-confirm.png)

#### 使用中のファイルの画面

トレイが動いていると、「インストールを続行するには、次のアプリケーションを終了する必要があります」という画面が出ます。一覧には、`kasane-tray` が出ます。

- **セットアップの完了後、アプリケーションを自動的に終了して、再起動する**: アンインストールのあとで、パソコンが自動で再起動します。
- **アプリケーションを終了しない (再起動が必要になる場合があります)**: 再起動は、自分で行います。

どちらを選んでも、アンインストールは完了します。手順 3 の再起動は、どちらでも要ります。

### 3. 再起動する

パソコンを再起動します。再起動した時点で、ドライバの削除が完了します。

## 削除されるもの

| 項目 | 内容 |
|---|---|
| プログラム | `C:\Program Files\applet\kasane` の中身と、スタートメニューの項目 |
| ライセンス管理サービス | `kasaneLicenseSvc` |
| ドライバ | `kbdlayer` と、ドライバに保存されていた設定（キーマップ、マクロ、コンボ、タイミング、NICOLA、緊急解除の組み合わせなど） |
| 環境変数 | `KASANE`（インストーラーで指定していた場合） |
| 自動起動 | トレイの自動起動の登録 |

## 削除されずに残るもの

再インストールしたときに引き継ぐため、次のものは残ります。

| 場所 | 内容 |
|---|---|
| `%ProgramData%\kbdlayer-license` | ライセンスキーとログ。再インストールすると、このキーで自動的に再確認されるので、アクティベートし直す必要はありません |
| `%LOCALAPPDATA%\applet\kasane` | キーボードごとの設定（`project.json`）、トレイの設定、ログ。環境変数 `KASANE` を指定していた場合は、そのフォルダ |

## 完全に削除したいとき

アンインストールと再起動のあとで、上の 2 つのフォルダを手で削除してください。削除すると、保存した設定とライセンスキーが失われます。設定を残したいときは、先に[エクスポート](14-import-export.html)してください。

## 再インストールしたとき

- ライセンスは、保存されたキーで自動的に再確認されます。
- 保存したキーマップ（`project.json`）は、kasane を開くと読み込まれます。ドライバ側の設定は削除されているため、**キーボードに適用(ON)** を押すと、元に戻せます。
