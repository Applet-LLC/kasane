# 16. 付録

## トラブル対応

| 症状 | 原因と対処 |
|---|---|
| キーボードの一覧に「(ドライバ未接続: 編集とエクスポートのみ)」しか出ない | ドライバが読み込まれていないか、ライセンスが有効になっていません。インストール後に再起動したかと、[License Manager](03-license.html) の状態を確かめてください |
| **押して特定...** でキーを押しても、キーボードが見つからない | そのキーボードをドライバが認識していません。ライセンスの有効化のあとに、再起動したかを確かめてください |
| 「適用できません」と表示される | 表示された理由を直してから、もう一度適用します。このとき、キーボードの設定は変わっていません。例として、存在しないレイヤーへの `MO(n)` や、同じスキャンコードが 2 つのキーに記録されている場合があります（後者は、キャリブレーションのやり直しが要ります） |
| 設定したのに、違うキーが入れ替わる | 標準と違う信号を送るキーボードです。**キャリブレーション...** の個別キーのキャリブレーションで、そのキーを実測し、もう一度適用します（[6. キャリブレーション](06-calibration.html)） |
| 赤い枠のキーがある | どのキーか分からないキーです。変更したいときだけ、個別キーのキャリブレーションで実測します。変更しないなら、そのままで構いません |
| 「OFF なのに入れ替わる」「設定したのに効かない」 | ウィンドウのタイトルバーのドライバの状態（ON、OFF、設定なし）を、最初に見てください（[5. エディタの基本画面](05-editor-basics.html)） |
| 設定を誤って、入力できなくなった | 緊急解除の組み合わせを、3 秒間押し続けます（[7. 緊急解除](07-emergency.html)） |
| USB ポートを差し替えたら、あるいは Bluetooth のキーボードを再ペアリングしたら、設定が消えた | ポートごとに別のキーボードとして扱われます。元のポートに戻すか、エクスポートとインポートで移します（[15. バックアップと移行](15-backup-migrate.html)） |
| キーボードに適用(ON)が押せない | 閲覧専用モードです。画面上部の **管理者として再起動** を押します |
| インストールに失敗した | [1. インストール](01-install.html)の「うまくいかないとき」を見てください |

## 既知の制限

利用者に関わる主なものです。全体は `docs/KNOWN-ISSUES.md` にあります。

- Pause/Break を別のキーに置き換えると、押すたびに NumLock が切り替わります。Pause を置き換える設定は避けてください。何かのキーを Pause にする設定は動きます。
- 管理者でないときは、キャリブレーションの「入力確認」と、緊急解除の「同時押しを試す」が、Windows のキー入力（低レベルキーフック）で確認する方式になります。右 Shift が扱えない、一部のキーで解放が届かない、などの制限があります。管理者として起動すると、ドライバから直接受け取るので、正確に確認できます。
- 右 Shift を `E0 36` で出すキーボードは、キャリブレーションで扱えない場合があります（実機では未確認です）。
- IME の状態を TSF で取得する機能は、実験的です。使うと Explorer の起動が遅くなる問題が、解決していません（[10. IME連動とNICOLA](10-ime-nicola.html)）。

## 環境変数 KASANE

設定フォルダを指定します。絶対パスを入れたときだけ有効です。無効なときと未設定のときは、`%LOCALAPPDATA%\applet\kasane` を使います。

- 通常はインストーラーで指定します（[1. インストール](01-install.html)）。
- 値は、使うたびに読み直されます。変えたあとは、サインインし直してください。

## コマンドライン

通常の操作では使いません。インストーラーや、診断、ほかのツールから呼ぶためのものです。

| 実行ファイル | 引数 | 内容 |
|---|---|---|
| `kasane.exe` | `--install-import <ファイル>` | `*.kasane.json` をドライバのレジストリに書く。インストーラーが使う |
| `kasane.exe` | `--restore-import-backup [型番 または --all]` | インストール時の取り込み前の設定に戻す |
| `kasane.exe` | `--import-pending` | 設定フォルダの `kasane-import.json` を、設定のないキーボード分だけ取り込む。トレイが起動時に呼ぶ |
| `kasane.exe` | `--prepare-data-dir <フォルダ> <ファイル>` | 設定フォルダを作り、権限を付ける。インストーラーが使う |
| `kasane-tray.exe` | `--probe-ime` | 診断。3 秒待って、IME の状態を `%TEMP%\kasane-ime-probe.txt` に書く |
| `DriverManager.exe` | `install keyboard`, `uninstall keyboard`, `check-pending` | ドライバの導入、削除、削除待ちの確認。管理者権限が必要 |
| `KeymapTool.exe` | `--apply-simple` ほか | コマンド版の設定ツール |

コマンドで設定する方法は、`docs/TUTORIAL-CLI.md` にあります。

## ログとファイル

| 場所 | 内容 |
|---|---|
| 設定フォルダの `tray.log` | トレイの異常の記録 |
| 設定フォルダの `import.log` | 設定の取り込みの記録 |
| `%ProgramData%\applet\kasane\import.log` | インストール時の取り込みの結果 |
| `%ProgramData%\kbdlayer-license\debug.log` | ライセンスサービスのログ |
| `%ProgramData%\kbdlayer-license\gui-debug.log` | License Manager のログ |
| `%TEMP%\MSI*.LOG` | インストールのログ |
| Windows のイベントログ（ソース `kasaneLicenseSvc`） | ライセンスサービスのイベント |

## 内部名

| 名前 | 何のものか |
|---|---|
| `kbdlayer`, `kbdlayer.sys` | キーボードドライバ、およびそのサービス名 |
| `kbdlayer-license` | ライセンスの保存先、ライセンス管理が使う内部名 |
