# チュートリアル: kasane（GUI）でキーを入れ替える（JIS / US キーボード）

**kasane**（かさね）のGUIを使って、キーボードのキーを入れ替え、実際に動くことを確かめるまでの手順です。
コマンドは使いません（コマンドで行う方法は [TUTORIAL-CLI.md](TUTORIAL-CLI.md) を参照）。

例として、次の入れ替えを設定します。

| キーボード | 入れ替えるキー |
|---|---|
| JIS（日本語109キー） | **英数キー**（`Caps Lock 英数`と刻印されたキー）と **左Ctrl** |
| US（英語104キー） | **CapsLock** と **左Ctrl** |

---

## 0. 準備

インストールとライセンスの有効化がまだの場合は、[TUTORIAL-CLI.md](TUTORIAL-CLI.md) の
「0. 前提条件」「1. インストールする」「2. ライセンスを有効にする」を先に行ってください（2回の再起動を含みます）。

## 1. kasaneを起動する

スタートメニューから **kasane** を右クリックし、**管理者として実行** で起動します。

キーボードへの適用・個別キーと全体のキャリブレーション・キーボードの特定には管理者権限が必要です（キャリブレーションの画面の「入力確認」は、管理者権限が要りません）
（一般ユーザー権限のアプリにキー入力を盗み見られたり、勝手にキー入力を仕込まれたりしないように、ドライバが制限しています）。
普通に起動すると画面上部に「閲覧専用モード」と表示され、これらのボタンが使えません。
その場合は **管理者として再起動** を押してください。編集・エクスポート・OFFは閲覧専用モードでもできます（保存は、閉じるときなどに自動で行われます）。

画面にはキーボードの絵が表示されます。キーの左上の小さな文字がキーの刻印、中央の大きな文字が
そのキーに今割り当てられている動作です（何も変更していないキーは刻印と同じです）。

### タスクトレイ（常駐ツール）

インストールすると、次のログインから、タスクトレイ（画面右下の通知領域。隠れているときは「^」の中）に kasane のアイコンが
常駐します。
トレイを「終了」したあとは、スタートメニューの **kasane Tray**（`applet` フォルダ）から、次のログインを待たずに起動し直せます。すでに動いているときに押しても、2つ目は起動しません。

- **左クリック**: kasane（エディタ）を開きます（すでに開いていれば前面に出ます）。初回など起動に時間がかかるときは、画面が出るまで「準備しています」の小さな表示が出て、画面が出ると自動で消えます（最長30秒）。
- **右クリック**: メニューが開きます。上から次のとおりです。
  - **設定**: kasane（エディタ）を開きます。
  - **一時停止**: すべてのキーボードのリマップを止めて、素通しにします（アイコンが灰色になります）。もう一度押すと、止める前に
    ONだったキーボードがONに戻ります。リマップが効いているキーボードが無いときは押せません。
  - **レイヤー**: サブメニューで、レイヤー 1〜15 を手で入れ・切りします（キーが無いとき、試すときに便利です）。チェックは、今有効なレイヤーです。
    キーボードが複数あるときは、キーボードごとに分かれます。キーボード側の `TG` や、IME連動・アプリ別レイヤーが立てたレイヤーは、チェックが付いたまま
    **灰色**になり、ここからは切れません（お互いの OR になるため）。ここで入れたレイヤーは、もう一度選ぶと切れます。一時停止中や、リマップが効いているキーボードが無いときは押せません。
    **レイヤー 0 の項目はありません。** レイヤー 0 は基準（基底）のレイヤーで、常に有効なので、入れ・切りする対象ではないためです（メニューは、基底の上に手で重ねるレイヤーを操作します）。
    `DF(n)` で基底をレイヤー n に替えているときは、レイヤー n が基底になり、メニューの「レイヤー n」は、チェックが付いて灰色になります（レイヤー 0 は、項目が無いままです）。
  - **ライセンス**: ライセンス管理を開きます。
  - **終了**: トレイを終了します（「全般」タブの「トレイが動いている間だけ、キーのリマップを有効にする」がONの既定では、リマップもOFFになります。OFFにしているときは、リマップはそのままです。一時停止中に終了すると、停止したままになります）。
- アイコンにマウスを重ねると、状態（動作中・一時停止中・ドライバに接続できません）が出ます。NICOLAを設定しているときは、「NICOLA 入力中」「NICOLA 待機（IME連動）」も出ます。
- **トレイが動いている間だけ、リマップを有効にする**（設定...→「全般」タブ。**既定はON**）: ドライバは設定を保存しているので、Windows のログオン画面や、起動した直後（トレイが動く前）でもリマップを続けます。この設定がONだと、トレイの終了、サインアウト、シャットダウン、画面のロック（ユーザーの切り替えを含む）のときにリマップをOFF（素通し）にし、トレイが起動したとき、ロックを解除したときに、**このモードでOFFにしたキーボードだけ**をONに戻します（緊急解除や「OFF」ボタンで止めたキーボードは戻しません）。トレイが異常終了（クラッシュ・強制終了・電源断など）したときや、インストーラーがトレイを止めたときは、OFFにできません。OFFのまま使う場合は、この設定をOFFにしてください。
- **IME連動**: NICOLAを設定したキーボードがあると、トレイが、IMEがかなモードのときだけNICOLAのレイヤーを自動で立てます（メニューの項目はありません。止めたいときは、**設定...** →「NICOLA」の「IME連動」のチェックを外します）。
- **レイヤー表示**: アイコンの右下に、今のレイヤー番号（1〜9、10以上は A〜F）が出ます。ふつうの状態（基底のレイヤー 0 だけ）では何も出ません。`DF(n)` で基底を 0 以外のレイヤー n に替えていると、何も押していなくても、その番号 n が常に出ます（基底が 0 のときだけ、「基底だけなら出ない」になります）。ツールチップにも「レイヤー N」が出ます。アイコンの大半が隠れるので、出したくないときは、**設定...** →「NICOLA」の「トレイのアイコンに、今のレイヤー番号を重ねる」のチェックを外します。
- エディタは通常の権限で開きます。キーボードへの適用などで管理者権限が必要なときは、エディタの **管理者として再起動** を使います。
- 一時停止中にPCを再起動しても、停止したままです。トレイを起動し直して（ログインで自動起動します）「一時停止」を押すと
  戻せます。エディタで **キーボードに適用（ON）** を押しても戻ります。

## 2. 設定するキーボードを選ぶ

画面上部の **キーボード** の一覧から、設定したいキーボードを選びます。

一覧の各行は、次の順に表示されます（無いものは省かれます）。

`UniqId`（8桁）　**つけた名前**　Windows 上の名前（デバイスマネージャーの名前、製品名）　ハードウェアID

- **つけた名前:** **名前を付ける...** を押すと、いま選んでいるキーボードに、わかりやすい名前（例: 「仕事用」）を付けられます（空にすると消えます）。名前は設定の元データ（`project.json`）に入り、エクスポートのファイルにも入ります（取り込み先に名前がまだ無いときだけ引き継ぎます）。画面の表示だけに使い、キーの動作には関係しません。
- **Windows 上の名前:** デバイスマネージャーの名前（多くの USB キーボードでは「HID キーボード デバイス」）と、その USB／Bluetooth 機器が名乗っている製品名（例: `HHKB-Studio`）を表示します。同じ型番を2台つないでも、`UniqId` で区別して、それぞれの名前を出します。取れない（またはどのキーボードか決められない）ときは、出しません。**一覧を更新** で取り直します。

- ノートPCで外付けキーボードもつないでいる場合など、どれが目的のキーボードか分からないときは
  **押して特定...** を押し、目的のキーボードでどれかキーを1つ押してください。押したキーボードが選ばれます。
- 一覧に `(ドライバ未接続: 編集とエクスポートのみ)` しか無い場合は、ドライバが動いていないか、
  ライセンスが有効になっていません（[うまくいかないとき](#うまくいかないとき)を参照）。

## 3. レイアウトを確認する

画面上部の **レイアウト** が、お使いのキーボードと合っているか確認します。

- 日本語（JIS）キーボード: `JP109`
- 英語（US）キーボード: `US104`
- テンキー単体（17キー）: `10KEY`（[テンキー単体の場合](#テンキー単体の場合)を参照）

初回はWindowsの表示言語に合わせて `JP109` か `US104` が選ばれています。違っていたら切り替えてください
（切り替えると「割り当てがリセットされます」と確認されるので、**OK** を押します）。

### ほかの配列を使う（KLE から追加する）
同梱のレイアウトに無い配列（ISO、60%、テンキー付きの特殊な配列など）は、[Keyboard Layout Editor](https://www.keyboard-layout-editor.com/)（KLE）で作った配列を取り込んで使えます。

1. KLE のサイトで、配列を作る（上部の **Preset** から選んで直してもかまいません）。**Raw data** タブの内容を、JSON ファイルに保存する（または、**Download JSON**）。
   キーの回転（Rotate）は使えません。
2. kasane の **レイアウト** の横の **KLEから追加...** を押し、**ファイルを選ぶ...** で、そのファイルを開きます。
3. 確認画面で、各キーの既定のキーコードを、ラベルと位置から推定した結果が出ます。緑は確定、黄色は推定、赤は未割り当てです。
   推定が違うキーや、赤のキーは、一覧の **キーコード** を書き換えるか、**一覧から選ぶ...** で選びます（`KC_A`、`KC_LSHIFT` のような、1 つのキーの名前です）。
   赤のまま保存しても使えますが、そのキーは、[キャリブレーション](#キャリブレーション必要な場合だけ)が要ります。
4. **名前**（英数字とハイフン）をつけて、**保存して使う** を押します。`%LOCALAPPDATA%\applet\kasane\Layouts\kle-<名前>.json`（環境変数 `KASANE` を指定していれば、そのフォルダの `Layouts`）に保存され、**レイアウト** の一覧に出ます。
   同梱のレイアウト（`JP109`・`US104`・`10KEY`）と同じ名前は使えません。同じ名前で保存し直すと、上書きします。

> **キャリブレーションは通常不要です。** 標準的なJIS/USキーボードなら、絵の上のどのキーが
> 実際のどのキーかはレイアウトから自動で決まります。赤い枠のキー（どのキーか分からないキー）が
> ある場合や、設定したのに違うキーが入れ替わる場合だけ、[キャリブレーション](#キャリブレーション必要な場合だけ)を行ってください。

## 4. キーを入れ替える

画面上部の **レイヤー** が `0` になっていることを確認してから、次の2つを行います。

**JISキーボード:**

1. 絵の **英数（Caps Lock）** キーをクリックします。
2. 開いた画面の左の一覧から **修飾キー** を選び、**LCtrl（KC_LCTRL）** を押して **OK** を押します。
3. 絵の **左Ctrl（LCtrl）** キーをクリックします。
4. 左の一覧から **記号・編集** を選び、**Caps（KC_CAPSLOCK）** を押して **OK** を押します。

**USキーボード:** 上と同じ手順で、**Caps Lock** キーを `KC_LCTRL` に、**左Ctrl** キーを `KC_CAPSLOCK` にします。

変更したキーは青色になり、中央に新しい動作（`LCtrl` / `Caps`）が表示されます。

> 間違えたときは、そのキーを **右クリック** して「このレイヤーの割り当てを戻す」を選ぶと元に戻ります。

## 5. キーボードに適用する

画面下の **キーボードに適用（ON）** を押します。

画面下のステータス欄に「適用しました（ON）」と表示されれば完了です。この瞬間から入れ替えが効きます。
設定はドライバに保存されるので、PCを再起動しても有効なままです（kasaneを起動しておく必要もありません）。

## 6. 動作を確認する

メモ帳を開いて確認します。

**JISキーボード（英数 ⇔ 左Ctrl）**

- **英数キー** を押しながら `A` → 全選択される。`C` / `V` でコピー / 貼り付けができる。
- 日本語入力（IME）をオンにした状態で **左Ctrl** を押す → 英数キーとして動く。
- **Shift + 左Ctrl** → CapsLockが切り替わる。

**USキーボード（CapsLock ⇔ 左Ctrl）**

- **CapsLock** を押しながら `A` → 全選択される。`C` / `V` でコピー / 貼り付けができる。
- **左Ctrl** を押す → CapsLockが切り替わる（ランプが点灯/消灯する）。

どちらも、右Ctrlやその他のキーは今までどおり動きます。

## 7. 元に戻す

| やりたいこと | 操作 |
|---|---|
| 一時的に入れ替えを止める（設定は残る） | **OFF（素通しに戻す）** を押す。再開は **キーボードに適用（ON）** |
| 設定を変える | キーをクリックして変更し、もう一度 **キーボードに適用（ON）** |
| 入れ替えをやめる | 入れ替えたキーを右クリック →「このレイヤーの割り当てを戻す」→ **キーボードに適用（ON）** |
| アンインストールする | **OFF（素通しに戻す）** を押してから、Windowsの設定「アプリと機能」で「かさね Subscription」を削除し、PCを再起動する。ライセンスキーと、kasane で保存したキーマップ（`%LOCALAPPDATA%\applet\kasane`）は残るので、再インストールしたらアクティベートし直さずに **キーボードに適用（ON）** で元に戻せる（詳しくは配布物の `README.ja-JP.txt`） |

## テンキー単体の場合

テンキー単体（NumLock、/、*、-、0〜9、.、+、Enterの17キー）のキーボードでの例です。
**NumLockの状態に関係なく、数字キーが常に数字を入力する** ようにします。

普通、NumLockがOFFのときテンキーの数字キーは Home・End・矢印などとして働きます。この設定では
テンキーの数字キーを、キーボード最上段の数字キーと同じ信号に置き換えます。最上段の数字はNumLockの
影響を受けないので、いつでも数字が入力されます。

1. 手順2でテンキーを選び、**レイアウト** を `10KEY` にします。
2. テンキーの絵の **7** キーをクリックし、左の一覧から **数字** を選んで **7（KC_7）** を押し、**OK** を押します。
3. 同じようにして、**0〜9** の各キーをそれぞれ同じ数字（`KC_0`〜`KC_9`）にします。
4. **.** キーをクリックし、**記号・編集** の **.（KC_DOT）** にします。
5. **キーボードに適用（ON）** を押します。

**確認:** メモ帳を開き、NumLockを **OFF** にしてから（ランプが消えた状態）数字キーと`.`を押します。
矢印やHome/Endとして動かず、数字とピリオドが入力されれば成功です。NumLockをONにしても同じく数字が入力されます。

> 同じ内容のキーマップが、インストール先の `samples\tutorial-10key-numbers.json` にあります
> （CLIで適用する手順は [TUTORIAL-CLI.md](TUTORIAL-CLI.md) の「テンキー単体の場合」）。

## キャリブレーション（必要な場合だけ）

キャリブレーションは、絵の上のキーが実際のどのキーかを、実際にキーを押して確かめる作業です。

画面下の **キャリブレーション...** を押すと、キャリブレーションの画面が開きます。画面の上の **モード** で、次の3つから選びます（最初は「入力確認」です）。

- **入力確認**（最初のモード。管理者権限は要りません）: キーボードのキーを押すと、絵の上の対応するキーが橙色になり、離すと戻ります。**一度押したキーには ✓ が付く**ので、
  全部のキーを一通り押してみて、✓ が付かないキーや、押したキーと違うキーが光るキーがあれば、キャリブレーションが必要です。**確認済みをリセット** で ✓ を消せます。
  確認できるのは、レイヤーマップで置き換えた後のキーです（置き換えている場合は、先に **OFF（素通しに戻す）** を押してください）。どのキーボードからの入力かは区別できません。
- **個別キーのキャリブレーション**（管理者権限が必要）: 絵の上の実測したいキーをクリックして黄色にし、キーボードの対応するキーを押します。続けて、別のキーも実測できます。
- **全体のキャリブレーション**（管理者権限が必要）: 黄色で示されたキーを順番に押します。
  間違えたら **1つ戻る**、そのキーボードに無いキーは **このキーを飛ばす** を押します。

実測したら、**実測値を保存して閉じる** を押します。何も実測していないとき（入力確認だけのとき）は、**閉じる（実測値は保存しない）** で閉じます。

キャリブレーションの画面が前面にある間は、押したキーは **Windowsには送られません**（Enterや
Winキーを押しても何も起きません）。操作はマウスで行ってください。別のウィンドウをクリックすると
一時停止し、キーは普段どおりに戻ります。

実測した値が標準と違うキーは、絵の上でオレンジ色の枠になります。結果は **キーボードに適用（ON）** を
押したときに反映されます。

## その他の機能

**名前を付ける（レイヤー・マクロ・コンボ・タップダンス・キー置換）:** どれも内部では番号で扱いますが、わかりやすい名前を付けられます（名前は画面の表示とエクスポートのファイルだけに使い、キーの動作には関係しません）。レイヤーは、レイヤーの一覧を右クリックして **レイヤーNに名前を付ける...**。マクロ・コンボ・タップダンス・キー置換は、それぞれの編集画面の右側の先頭にある **名前（任意）** 欄に入れます（左の一覧に `番号: 名前 — 中身` と表示されます）。中身が空の番号は未使用なので、名前だけ付けても残りません。エクスポートしたファイルにも入り、取り込むときは、取り込み先に名前がまだ無いものにだけ引き継ぎます。

| 機能 | 操作 |
|---|---|
| レイヤー | **＋ 追加** でレイヤーを増やし、レイヤー0のどれかのキーに「レイヤー操作」の `MO(1)` 等を割り当てると、そのキーを押している間だけレイヤー1の割り当てになる。`▽` は「下のレイヤーと同じ」。 |
| 修飾キー付きのキー（ショートカット） | キーの割り当て画面の下にある修飾キーのチェックボックス（左Ctrl・左Shift…）をチェックしてからキーを選ぶ。例: 左Ctrlをチェックして C → `LCTL(KC_C)`（Ctrl+C）。絵の上では `^C` のように表示される。キーコード欄に `LCTL(LSFT(KC_T))` のように直接書いてもよい。押したまま次のキーを押すと、足した修飾キーは次のキーには掛からない（「!」を打つキーの直後の「a」は「a」のまま）。 |
| LM（レイヤー＋修飾キー） | 「レイヤー操作」で `LM` を選び、レイヤーと修飾キー（チェックボックス）を指定する。押している間、そのレイヤーを有効にし、修飾キーも押した状態になる。例: `LM(1,MOD_LCTL)` を押したまま、レイヤー1で `▽` のままのCを押すと Ctrl+C。 |
| Mod-Tap / Layer-Tap | キーの割り当て画面の「Mod-Tap (MT)」「Layer-Tap (LT)」。短く押すと普通のキー、長押しで修飾キー／レイヤーになる。押している間に別のキーを押すと長押し扱いになり、そのキーは切り替わった後のレイヤーの割り当てで入力される（例: `LT(1,KC_SPC)` を押しながら J → レイヤー1の J の位置のキー）。短く押した直後にもう一度押し続けると、短く押したときのキーのリピートになる（スペースを連打・長押しできる）。 |
| 出力キーの入力補助 | キーを文字で書かなくても入力できる。キーコードの欄（キー割り当て・マクロ・コンボ・タップダンス・キー置換・ヘルパー動作のトリガー）には、**押して入力**（押したあとに入力したいキーを押すと、そのキーのキーコード名が入る。Esc で取消）と、**選ぶ...**（画面上のキーボードや一覧から選ぶ。修飾キーにチェックすると `LCTL(KC_C)` のような形になる）のボタンがある。キー割り当て画面では、左の一覧の末尾の「画面のキーボード」からも選べる。Win キーや Alt+Tab のように OS が先に処理するキーは「押して入力」では取れないので、「選ぶ...」を使う。左右の修飾キーやテンキーの Enter、日本語キー（無変換・変換など）は区別して入る。 |
| マクロ | 画面下の **マクロ...** で中身（順に打つキー）を作り、キーに `MACRO(n)` を割り当てる。128個（0〜127）まで作れる。中身に `LCTL(KC_C)` のような修飾キー付きのキーも書ける。 |
| コンボ | 画面下の **コンボ...** で「2つのキーの同時押し → 別のキー」を設定する。出力には、普通のキーのほか `LCTL(KC_Z)` のような修飾キー付きのキー（押している間）や `MACRO(n)`（成立したときに1回）も指定できる。 |
| タップダンス | 画面下の **タップダンス...** で中身を作り、キーに `TAPDANCE(n)` を割り当てる。1回・2回・3回タップには、普通のキーのほか `LCTL(KC_C)` のような修飾キー付きのキーや `MACRO(n)` も指定できる。長押しには、`MT`・`LT` のほか、修飾キー付きのキー（押している間）、`LM(1,MOD_LCTL)`、`MACRO(n)`（長押しが決まったときに1回）も指定できる。空欄にした欄は「動作なし」（そのタップ回数・長押しでは何も起きない）。 |
| One Shot（OSM） | 「レイヤー操作」で `OSM` を選び、修飾キーのチェックボックスで修飾キーを選ぶ。そのキーを短く押して離すと、次に押すキー1回だけにその修飾キーが掛かる（例: Shift の OSM → a で「A」）。押したまま使えば普通の修飾キー。待っている間にもう一度タップすると取り消し。 |
| キー置換 | 画面下の **キー置換...** で「修飾キー＋キー → 別のキー」を設定する。例: 修飾キー `MOD_LSFT`・キー `KC_BSPACE`・置き換え先 `KC_DELETE` で、Shift+BS が Delete になる。US 配列の刻印のキーボードを JIS 設定の Windows で使う場合は、`MOD_LSFT`・`KC_2`・`KC_LBRC` で Shift+2 が @ になる。置き換えている間、条件の修飾キーは一時的に離される。 |
| TO / TT | 「レイヤー操作」の `TO(n)` は、レイヤーnだけを有効にする（他のレイヤーはOFF）。`TT(n)` は、押している間だけレイヤーnを有効にし、続けて素早くタップするとON/OFFを固定する（既定は5回。もう一度同じ回数で解除。回数は **設定...** の「タイミング」タブで変更）。 |
| 設定 | 画面下の **設定...** で、タブ形式の設定画面を開く。「機能」「タイミング」「NICOLA」の3つは **OK** の後に **キーボードに適用（ON）** を押すと反映される。「共有範囲」は、タブの中のボタンを押したときにすぐ反映される（OK・キャンセルとは関係しない）。「緊急解除」は、別のタブに移るとき、または **OK** を押したときに反映される（管理者として実行したときだけ）。 |
| タイミング（設定のタブ） | 長押し・同時押し・連続タップの判定時間を変える。MT/LT の判定方式（別のキーを押したらすぐ長押し扱い／押して離したら長押し扱い／時間内に離せば短押し扱い）、Quick Tap（使うかどうかと時間）、TT の固定に必要なタップ回数もここで変える。速く打つと MT が意図せず長押し扱いになる場合は、2つ目か3つ目の方式を試す。 |
| 機能（設定のタブ） | マクロ・コンボ・タップダンス・キー置換を、使わなければ OFF にできる。OFF にした機能のキーは何もせず、コンボの構成キーは普通のキーとして動く。OFF にしても中身（マクロの定義など）は消えない。チェックに一度も触れていなければ、適用してもキーボードの設定は変わらない（CLI の `--set-features` で変えた値がそのまま残る）。 |
| NICOLA（設定のタブ） | 親指シフトを使う。「この設定を使う」を選ぶと NICOLA 規格書どおりの配列が入る。**表を編集...** で、IME の入力方式（ローマ字／JISかな）、親指キー、判定時間、各キーの「単独／親指左／親指右」で出すかなを変えられる。CLI と同じ形式の `nicola.json` の読み込み・書き出しもできる。指定したレイヤー（既定は1）が有効な間だけ働く。**IME連動**（既定でON）にしておくと、IMEがかなモードのときだけ、タスクトレイの kasane が自動でそのレイヤーを立てる（切り替えるキーは要らない。使わない場合は、そのレイヤーに切り替えるキー（例: `TG(1)`）をキーマップに置く）。適用のときに、親指キーの単独打鍵のキー（`thumbLeftTap`・`thumbRightTap`。Enter・Spaceなど）が、NICOLAのレイヤーのキー割り当てとして自動で足される（Ctrl・Shiftなどを押している間は、NICOLAの判定が行われず、この割り当てが使われる。キー割り当てが1つも無くても、NICOLAが動く）。「GUIでは管理しない」のままなら、CLI の `--set-nicola` で入れた設定は適用しても変わらない。例: 無変換・変換を Enter・Space にして使うには、`samples\nicola-enter-space.json` を読み込み、Windowsの IME の設定で無変換キーを「IME-オン」にする（[TUTORIAL-CLI.md](TUTORIAL-CLI.md) の「例: 無変換・変換を Enter・Space にして…」）。 |
| ヘルパー動作（設定のタブ。詳しくは [HELPER.md](HELPER.md)） | キーで、プログラムの起動・URL やファイルを開く・文字列の入力（日本語も可）・キー入力・マウス操作・レイヤーの操作・一時停止の切り替えを動かす。管理者権限は要らず、**OK** で保存すると、タスクトレイの kasane が数秒で読み直す。対象は「このキーボード」か「全キーボード共通」。**動作**（Id つき）は、キーの割り当て画面の「ヘルパー動作」から選ぶ（または **新しい動作...** で作る）と `HLP(Id)` になる。そのキーを押すと、キー自体は何も出さず、トレイが動作を実行する（トレイが動いている必要がある）。**トリガー**は、F13〜F24 などのキー（と Ctrl・Shift・Alt・Win の組み合わせ）をトレイが見張って動かす（押したキーは飲み込まれてアプリには届かない。F13〜F24 は、キーの割り当てで出せる）。キー入力の手順は、1行1手順（`key LCTL(KC_C)`、`text こんにちは\n`、`delay 50`、`mouse left`、`move 10 -5`、`wheel -120` など。書き方は編集画面に出る）。管理者として動くウィンドウには、キー・マウスの入力が届かない。一時停止中は、一時停止の切り替えだけが動く。 動作の編集画面の「キー・文字列・マウスの操作 (Sequence)」では、手順の欄の上のボタン（**キーを押して挿入**・**選んで挿入...**・**マウス操作を挿入 ▾**）で、キー名やマウス操作の行を、カーソルのある行の次に挿入できる。 |
| アプリ別レイヤー（設定のタブ） | 前面のアプリに応じて、アプリ管理レイヤーを自動で立てる、またはそのキーボードのリマップを OFF（素通し）にする（ゲームなど）。規則は上から順に見て、最初に一致したものを使う（キーボードごとの規則が先、どれにも一致しなければ「既定」の規則）。条件は exe の名前・パスやタイトルの正規表現・ウィンドウのクラス（のどかの window と同じ文字列の照合も可）。**実行中のアプリから選ぶ...** で、開いているウィンドウから exe とクラスを入れられる。**OK** で保存すると、トレイが数秒で読み直す。 |
| 緊急解除（設定のタブ） | 設定を誤って入力できなくなったときの逃げ道。ここで決めた2〜6個のキーを同時に3秒押し続けると、接続中の全キーボードが OFF（素通し）になる。既定は左右Ctrl＋左右Shift。**同時押しを試す...** で、そのキーボードが組み合わせを同時に検出できるか確かめられる（全部が緑になったら、3秒たつ前に離す）。各欄の **押して入力**（次に押したキーが入る）か **選ぶ...** でキーを入れられる（キー名を手で書く必要はない）。**クリア** で全部の欄を空にし、**既定（左右Ctrl＋左右Shift）にする** で既定の組み合わせを入れる。入れた組み合わせは、別のタブに移るとき、または **OK** を押したときに反映される（欄が全部空なら変更しない。キーが1個だけ、同じキーの重複、単純なキー以外はエラーになり、タブを移れない）。 |
| 保存先（設定のタブ） | 設定ファイル（キーボードごとの設定・トレイの設定・ログ）を保存しているフォルダと、環境変数 `KASANE` の値を表示する。`KASANE` に絶対パスが設定されていればそのフォルダ、無ければ `%LOCALAPPDATA%\applet\kasane` を使う。値の変更はインストーラーの「設定フォルダの指定」で行う（変更後はサインインし直す）。**フォルダを開く** で、エクスプローラーで開ける。 |
| インストール時の設定ファイルの取り込み | インストーラーの「設定ファイルの取り込み」（既定はオフ）で、kasane の **インポート／エクスポート** で書き出した設定ファイル（`*.kasane.json`）を選ぶと、インストール時の管理者権限で、その内容を **ドライバのレジストリ** へ書く（ドライバが動いていなくてもよい）。管理者保護の環境で、インストール後に **キーボードに適用（ON）** できない場合のためのもの。ファイルの中のキーボードは、型番（HardwareId）で対応づけ、「同じ型番で共有」の保存先（`LayerMaps\M_<ModelKey>`）へ書く（HardwareId が無いキーボード、レイヤー1枚だけのファイルは取り込めない）。反映は、再起動後（またはキーボードを接続し直したとき）。すでに設定がある型番は**置き換わり**、前の設定は `M_<ModelKey>.bak` へ**1世代だけ**退避される。結果は `%ProgramData%\applet\kasane\import.log`。サイレントインストールは `IMPORT_SETTINGS=1 IMPORT_SETTINGS_FILE=C:\path\x.kasane.json` で渡せる。 |
| インストール時の取り込みを戻す | 設定画面の **設定...** →「保存先」タブの下部に、退避がある型番が一覧で出る。**取り込み前の設定に戻す** は、退避と今の設定の入れ替え（もう一度押すと元に戻る）。ドライバのレジストリを書くので、**管理者として再起動**したときだけ押せる。反映は、キーボードを接続し直したあと（またはPCの再起動後）。 |
| 保存先のフォルダの取り込み（KASANE） | `KASANE` を指定したときに、インストール時の取り込みを選ぶと、同じファイルが `kasane-import.json` としてそのフォルダに置かれる。トレイと設定画面は、起動時に、**まだ設定が無いものだけ**（接続中のキーボードの `project.json`・`helper.json`、トレイの `tray.json`）を取り込む。すでにある設定は上書きしない。未接続のキーボードの分は、接続したあとの起動で取り込まれる。インストーラーは、指定したフォルダが無ければ作り、Users に変更権限を付ける（すでにあるフォルダの権限は触らない）。 |
| 共有範囲（設定のタブ） | キーボードは接続先（USBポート等）ごとに別のものとして扱われ、設定画面で作った設定（project.json）とトレイの設定（ヘルパー動作・アプリ別レイヤー・一時停止）は、ポートを替えると引き継がれない（エクスポート／インポートで移せる）。共有範囲は、ドライバが保存する設定の単位。同じ型番のキーボードで設定を共有する（既定）か、この1台（この差し込み口）だけの設定にするか、すべてのキーボードで1つの設定を共有するかを選び、**変更する** で反映する。「すべてのキーボードで共有」は、配列の違うキーボード（JISとテンキーなど）を混ぜると意図しない割り当てになるので、接続中に型番の違うキーボードがあると確認が出る。切り替えるときは今の設定が切替先へコピーされ、切替先の既存の設定は上書きされる（たとえば「すべて」や「この1台」から「同じ型番」へ戻すと、同じ型番で共有している設定が置き換わる）。同じ型番の別のキーボードへの反映は、そのキーボードを接続し直す（またはPCを再起動する）まで行われない。 |

- **保存:** 保存ボタンはありません。編集した設定は、kasane を閉じるとき、別のキーボードに切り替えるとき、**キーボードに適用（ON）** を押したときに、自動で
  `%LOCALAPPDATA%\applet\kasane\<キーボードのID>\project.json` に保存されます（環境変数 `KASANE` を指定していれば、そのフォルダの下です）（以前の版で `%LOCALAPPDATA%\LayerDriver\` に保存した設定は、初めて開いたときにここへコピーされます）。次に起動したときは、
  このファイルから前回の設定が読み込まれます。
- **閉じるときの確認:** 保存したが、キーボードに反映していない（適用していない）設定があると、閉じるときに確認が出ます。
  - 管理者として起動していない（閲覧専用）ときは、「設定は保存されましたが、キーボードに反映されていません。必要に応じて、管理者権限で反映してください」と出ます。**キャンセル**で閉じずに戻れます。
  - 管理者として起動しているときは、「反映しますか？」と出ます。**はい**で反映して閉じ、**いいえ**で反映せずに閉じ（設定は保存済み）、**キャンセル**で戻ります。
  - 保存済みの設定が読めない、またはそのレイアウトが見つからないときは、保存済みの設定を使わずに開きます。この状態では自動では保存せず、閉じるときなどに「保存すると置き換わります」と確認します（元の設定を失わないため）。
- **適用で送るもの:** **キーボードに適用（ON）** は、画面で編集している内容（キーの割り当て・マクロ等・設定ダイアログの
  機能・タイミング・NICOLA）を、まとめてキーボードに送ります。CLI で別のキーマップを入れていた場合も、
  GUI の内容で置き換わります。
- **インポート／エクスポート...:** 設定をファイル（`*.kasane.json`）に書き出す・読み込みます。範囲は **全体一括**（すべてのキーボードとトレイの設定）、
  **このキーボード**、**レイヤー1枚**（そのレイヤーが使うマクロ・タップダンス・ヘルパー動作も一緒に）の3つです。レイヤー一覧を右クリックしても開けます。
  キーはスキャンコードで書くので、レイアウトの違うキーボードにも読み込めます（今のレイアウトに無いキーは、読み込まずに画面に出ます）。
  読み込みは、項目（レイヤー・マクロ・コンボ…）を選び、**置き換え**か**追加**（今の設定を残して足す。番号が重なるマクロなどは付け直されます）を選びます。
  読み込んだ内容は編集中の状態に入るだけなので、**キーボードに適用**はそのあとで行います（保存は自動です）（ヘルパー設定だけは、すぐ保存されます）。
  全体一括の読み込みは、先に今の設定を `backup` フォルダへ自動でバックアップします。
- **のどかの設定を取り込む（インポート画面の中）:** のどか（nodoka4）の `.nodoka` を変換して取り込みます。のどかの設定一覧から選ぶか、ファイルを選びます。
  変換できたもの・近似したもの・変換できないものが、`ファイル名:行` つきで出ます。取り込みは「追加」が既定です。詳しくは `docs/IMPORT-NODOKA.md`。
- **エクスポート（KeymapTool用JSON）...:** `keymap.json` と `profile.json` を書き出します。コマンドラインそのものではなく、
  コマンドライン版の `KeymapTool --apply-simple` に渡す入力ファイルです（CLIで管理したい場合に使います）。
  マクロ・コンボ・タップダンス・キー置換は含まれません（`KeymapTool` の `--set-macro` などで別に設定します）。
  設定のバックアップや、ほかのPCへの受け渡しには、上の **インポート／エクスポート...** を使ってください。

### 例: F13 やブラウザーの「戻る」キーを割り当てる

キーの割り当て画面で、次のキーを選べます（物理キーが無いキーも、出力としては割り当てられます）。

| 左の一覧 | 選べるキー |
|---|---|
| ファンクション | F1〜**F24**（F13〜F24 は、ほかのツールやヘルパーのトリガーに使うと便利です） |
| メディア・システム | 音量・再生、電卓、**ブラウザー**（検索・ホーム・戻る・進む・中止・更新・お気に入り）、**メール**・メディア選択・マイコンピュータ、**スリープ・電源・ウェイクアップ** |

- 一覧に無いキーは、キーコードの入力欄に **`SC_XXXX`** と直接書けます。`XXXX` は 16 進 4 桁のスキャンコード（上位 2 桁は `00` か `E0` か `E1`、
  下位 2 桁は `00` 以外）で、例えばブラウザーの「戻る」は `SC_E06A` です。名前の無いキーを、ドライバから読み込んだときも `SC_XXXX` で表示されます。
- 修飾キーのチェックボックスを付けると、`SC_XXXX` のキーにも修飾キーを重ねられます（`LCTL(SC_E06A)` など）。
- **電源キー（スリープ・電源・ウェイクアップ）** は、割り当てるときに確認が出ます（押すと PC がスリープ・シャットダウンすることがあるため）。
  キートップにも ⚠ が付きます。

### 例: キーでメモ帳を起動する（ヘルパー動作）

タスクトレイの kasane が動いていれば、キーでプログラムの起動・文字列の入力・マウス操作などを動かせます（詳しくは [HELPER.md](HELPER.md)）。

1. メイン画面で、メモ帳を起動させたいキーをクリックします。
2. 開いた画面の左の一覧から **ヘルパー動作** を選び、**新しい動作...** を押します。
3. 種類を **プログラムを起動する (Launch)** にして、パスに `notepad.exe` を入れ、名前を付けて **OK** を押します。キーに `HLP(1)` のようなコードが入ります。**OK** で閉じます。
4. **キーボードに適用（ON）** を押します（`HLP(n)` もキーの割り当てなので、適用が要ります）。
5. そのキーを押すと、何も入力されずにメモ帳が起動します。

> 動作は `%LOCALAPPDATA%\applet\kasane\<キーボードID>\helper.json` に保存され、数秒でトレイに反映されます。
> F13 などのキーで動かしたいときは、**設定...** の **ヘルパー動作** タブの **トリガー** に作ります（こちらは適用が要りません）。

### 例: 特定のアプリでだけレイヤーを変える

前面のアプリに合わせて、レイヤーを立てたり、リマップを止めたりできます。

1. 画面下の **設定...** → **アプリ別レイヤー** タブを開きます。
2. 対象（このキーボード／全キーボード共通）を選び、**追加...** を押します。
3. **実行中のアプリから選ぶ...** で、対象のアプリのウィンドウを選びます（exe の名前が入ります）。
4. 立てるレイヤー（0〜15）にチェックを付けます（ゲームなどでリマップを止めたいときは、「リマップをOFFにする」にチェック）。**OK** を押します。
5. 設定ダイアログも **OK** で閉じると、保存されます。そのアプリが前面のときだけ、レイヤーが立ちます。

規則は上から順に見て、最初に一致したものを使います。**上へ／下へ** で順番を変えられます。IME 連動（NICOLA）のレイヤーとは別に重なります。

### 例: 親指シフトで、無変換・変換を Enter・Space にして、IMEに合わせて切り替える

親指シフト（NICOLA）の使い方の例です。次の動作になります。

| 操作 | 動作 |
|---|---|
| 無変換 = 親指左、変換 = 親指右 | 文字キーとの同時打鍵で、規格どおりの文字 |
| IMEがOFFのとき、無変換を単独で押す | IMEがON（手順2のWindowsの設定） |
| IMEがONのとき、無変換を単独で押す | Enter |
| IMEがONのとき、変換を単独で押す | スペース |
| Ctrl・Shiftを押しながら無変換・変換 | Ctrl+Enter、Shift+Space など |

1. **設定...** →「NICOLA」タブで、「この設定を使う」を選び、**nicola.json を読み込む** で `samples\nicola-enter-space.json`
   を選びます（親指キーの単独打鍵が Enter・Space になります）。ローマ字入力でなくJISかな入力のときは、**表を編集...** で
   IMEの入力方式を合わせます。「IME連動」にチェックが入っていることを確認して **OK** を押します。
2. Windowsの設定で、**無変換キーを「IME-オン」**にします（Microsoft IME の「キーとタッチのカスタマイズ」。
   画面の名前はWindowsの版で少し違います）。IMEがOFFのときはNICOLAが働かないので、無変換がIMEに届いてIMEがONになります。
   変換キーも「IME-オン」になっている場合は、「変換」に戻しておくと、変換を変換のまま使えます。
3. **キーボードに適用（ON）** を押します。Ctrl・Shiftと組み合わせたときのために、Enter・Space の割り当てが
   NICOLAのレイヤーのキー割り当てとして自動で足されます（キー割り当てが無くても動きます）。
4. タスクトレイの kasane が動いていることを確認します。IMEをONにすると、0.1秒ほど後にNICOLAに切り替わり、
   トレイのアイコンのツールチップが「NICOLA 入力中」になります。IMEをOFF（半角英数）にすると、ふつうのキーに戻ります。

親指キーの単独打鍵は、同時打鍵判定時間（既定 100ms）が過ぎるか、離したときに確定します。IME連動だけをやめるときは、
NICOLAタブの「IME連動」のチェックを外します。CLIでの手順は
[TUTORIAL-CLI.md](TUTORIAL-CLI.md) の「例: 無変換・変換を Enter・Space にして…」を参照してください。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| キーボードの一覧に `(ドライバ未接続...)` しか無い | ドライバが読み込まれていないか、ライセンスが有効になっていません。[TUTORIAL-CLI.md](TUTORIAL-CLI.md) の手順0〜2（テスト署名モード・再起動・ライセンス）を確認してください。 |
| **押して特定...** でキーを押しても見つからない | そのキーボードをドライバが認識していません（ライセンス有効化後に再起動したか確認してください）。 |
| 「適用できません」と表示される | 表示された理由を直してから、もう一度適用してください（この場合キーボードの設定は何も変わっていません）。例: 存在しないレイヤーへの `MO(n)`、同じスキャンコードが2つのキーに記録されている（キャリブレーションのやり直しが必要）。 |
| 設定したのに違うキーが入れ替わる | 標準と違う信号を送るキーボードです。入れ替えたいキーを右クリックして「このキーを実測する...」を行い、もう一度適用してください。 |
| 赤い枠のキーがある | どのキーか分からないキーです。そのキーを変更したい場合は、**キャリブレーション...** の「個別キーのキャリブレーション」で実測してください（変更しないなら放っておいて構いません。そのまま普段どおり動きます）。 |
| USBポートを差し替えたら設定が消えた | ポートごとに別のキーボード扱いになります。元のポートに戻すか、新しいポートでも設定してください。 |
