1. nodoka4 （のどか）  — Eclipse Public License 2.0
--------------------------------------------------------------------------------
使っている場所:
  kasane（kasane.exe）の、のどかの設定ファイル（.nodoka）の取り込み機能。次のファイルは、nodoka4 のソースコードを
  C# に移したものです。
    NodokaTokenizer.cs  ← parser.cpp（Parser::getLine, interpretMetaCharacters）、setting.cpp（前置トークンの表）
    NodokaParser.cs     ← setting.cpp（SettingLoader の、設定を読む部分）
    NodokaText.cs       ← setting.cpp（readFile）、parser.cpp（getLine）の、文字コードの判定と行の分け方
    NodokaModel.cs      ← keyboard.h（Modifier）
    NodokaVKeys.cs      ← vkeytable.cpp（g_vkeyTable の仮想キー名）
    NodokaImporter.cs   ← setting.cpp（getHomeDirectories）の include の探し方
  設定ファイルの文法（前置トークン、`def key` などの構文）も、nodoka4 の仕様に従っています。

4. 配列データ（キーボードの図）  — Keyboard Layout Editor（KLE）ほか
--------------------------------------------------------------------------------
使っている場所: kasane.exe の Layouts フォルダにある kle-10key.json、kle-us104.json、kle-jp109.json（キーボードの図の配列データ）。
各キーの既定のキーコードを凡例インデックス 4 に埋め込むなど、kasane 向けに手を加えています。

出典:
  kle-10key.json
    Keyboard Layout Editor  https://www.keyboard-layout-editor.com/  の最初に表示される 10 キーの配列（Raw data）を、
    「Download JSON」で入手して、kasane 向けに手を加えたもの。
  kle-us104.json（US keyboard (ANSI 104)）、kle-jp109.json（Japanese keyboard (OADG 109A)）
    hiroyuki-komatsu/keyboard_layouts  https://github.com/hiroyuki-komatsu/keyboard_layouts  の、該当する配列のリンクから
    Keyboard Layout Editor を開き、そこからダウンロードしたものをもとに、kasane 向けに手を加えたもの。

Keyboard Layout Editor は、Copyright (C) 2013-2018 by Ian Prest です。ライセンスと、入力（利用者のキーボード配列）・
出力（描画されたキーボード）の扱いについての記載は、third-party\keyboard-layout-editor-LICENSE.md にあります。
kasane は、Keyboard Layout Editor のソフトウェアを含まず、そこから得た配列データ（JSON）だけを使っています。
