かさね Pro インストールガイド 1.02 2026-11-16 Applet LLC
================================================================================

このパッケージは、かさねと名付けたキーリマップツールをインストールします。
インストーラーでは、Windowsカーネルモードのキーボードクラスフィルタドライバ「kbd
layer.sys」と設定ツールをインストールします。キーボードレイヤーで実現可能な（レイ
ヤー切り替え、Mod-Tap、Layer-Tapなど）をドライバ自身がエミュレートします。
リマップ動作は、デバイスドライバだけで動きますが、IMEの状態取得にはタスクトレイ
への常駐アプリが担当し、IME有効時にレイヤーの変更が可能です。

かさねのデバイス識別は、kbdaddid.sysからフォークされており、デバイスごとの識別の
仕組みをそのまま引き継いでいます。複数台のキーボードを同時に接続していても、特定
の1台にだけレイヤーキーマップを適用できます。

本エディションは買い切り版です。Gumroadで購入したライセンスキーを、インストール時に確認します。


動作環境
--------
- Windows 11 25H2（x64 または ARM64）
- インストールのための管理者権限
- インターネット接続。インストール時に、ライセンスキーをGumroadに問い合わせて確認します。
  確認はこの1回だけで、インストール後は接続が要りません。
  接続先は https://api.gumroad.com/v2/licenses/verify（HTTPS、443番）です。社内の
  ネットワークなどで止められていると、インストールが失敗します。


インストール手順
----------------

Subscription 版から移るときは、先に Subscription 版をアンインストールして
再起動してください。同じパソコンに両方は入れられません。

1. 「Install-kasane-pro.exe」を実行します。ライセンスキーの入力欄に、Gumroadで購入したキー
を貼り付けて、「インストール」を押します。

2. セットアップウィザードの指示に従い、キーボードドライバ、アプリがインストールされます。
   インストール先は C:\Program Files\applet\kasane に固定されています。

3. 設定フォルダ（任意）
   設定ファイル（キーボードごとの設定、トレイの設定、ログ）の保存先を、環境変数
   KASANE で指定できます。
   空欄のままなら、各ユーザーの %LOCALAPPDATA%\applet\kasane に保存されます。
   指定したフォルダが無ければ、作成します。

4. 設定ファイルの取り込み（任意。既定はオフ）
   かさね で書き出した設定ファイル（*.kasane.json）を、インストール時にドライバ
   へ反映します。

5. インストールを完了するには、再起動が必要です。

6. 再起動すると、使えるようになります(キーボードを接続し直しても反映されます)。


タスクトレイ
------------
ログインすると、タスクトレイ（通知領域。隠れているときは「^」の中）に かさね の
アイコンが表示されます。
- 左クリック: かさね の設定ダイアログを開きます。
- 右クリック: 設定、一時停止、レイヤー、バージョン情報、終了のメニューが出ます。
  「一時停止」を押すと、すべてのキーボードのリマップを一時的に止めます。もう一度
  押すと再開します。
- NICOLA(親指シフト)を設定している場合、IMEが有効になると自動でNICOLAになります。
  かさね の「設定」→「IME 連動」の下部でON/OFFを切り替えできます。
- ヘルパー動作: キーを押して、プログラムの起動、文字列の入力、マウス操作、
  レイヤーの切り替えなどを実行できます。かさね のキー割り当て画面の「ヘルパー
  動作」から作ります（トレイが動いている必要があります）。F13〜F24などのキーで
  動かす設定は、「設定」→「ヘルパー動作」にあります。
- アプリ別レイヤー: 前面にあるアプリに合わせて、レイヤーを切り替えたり、リマップ
  を止めたりできます。「設定」→「アプリ別レイヤー」にあります。
- インポート／エクスポート: かさね の「インポート／エクスポート...」で、設定を
  ファイル（*.kasane.json）に保存したり、読み込んだりできます。別のキーボードや
  別のパソコンに設定を移せます。のどか（nodoka）の設定ファイルも、変換して
  取り込めます。

ドライバが読み込まれていない状況では、リマップは効きません。
キーボードの基本的な入力は、そのまま使えます。


ヘルプ
------
かさね のヘルプは、編集画面の「ヘルプ」ボタン（F1キー）と、トレイのメニューの「ヘルプ」
から開きます。インストール先の manual フォルダにあります。
ヘルプの英語版は、まだ用意していません。ブラウザーの翻訳機能をお使いください。
ただし、画面の図は、日本語表示のままです。

アンインストール
----------------
1. 先に かさね を開き、「OFF」を押します。
   キーボードのリマップ動作が無効となります。
2. Windowsの設定の「アプリと機能」から、「かさね Pro」を削除します
   （管理者の権限が必要です）。
3. PCを再起動します。ドライバはキーボードで使用中のため、再起動した時点で削除が
   完了します。再起動するまでは、ドライバが動いたままのことがあります（手順1で
   OFFにしておけば、キーの割り当ては効きません）。

削除されるもの:
- プログラム（C:\Program Files\applet\kasane）とスタートメニューの項目
- ドライバ（kbdlayer）と、ドライバに保存されていた設定（キーマップ、マクロ、
  コンボ、タイミング、NICOLA、緊急解除の組み合わせなど）

削除されずに残るもの:
  再インストールしたときに引き継ぐため、以下が残ります。
- %LOCALAPPDATA%\applet\kasaneフォルダ、あるいは KASANE 環境変数で指定された
  フォルダの各ファイル。

完全に削除したい場合は、アンインストールと再起動の後に、このフォルダを手で
削除してください。

上書きインストール（新しい版をそのままインストールする方法）では、ドライバの設定
がそのまま引き継がれ、ライセンスキーの再入力も不要です。アンインストールは不要です。
アンインストールしてから入れ直すときは、ライセンスキーを入力し直します。
