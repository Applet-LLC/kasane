かさね Subscription インストールガイド 1.00 2026-08-19 Applet LLC
================================================================================

このパッケージは、Windowsカーネルモードのキーボードクラスフィルタドライバ
「kbdlayer.sys」をインストールします。QMK/VIA/VIAL形式のキーボードレイヤー
（レイヤー切り替え、Mod-Tap、Layer-Tapなど）をドライバレベルで直接エミュレート
するため、リマップ後のレイアウトがゲーム中やログイン画面を含めシステム全体で
機能します。キーボードとWindowsの間に常駐するユーザーモードのプロセスを挟み
ません。

かさね（kasane）は、同じ作者によるデバイス識別ドライバkbdaddidからフォークされて
おり、そのデバイスごとの識別基盤をそのまま流用しています。これにより、
複数台のキーボードを同時接続していても、特定の1台にだけレイヤーキーマップを
適用できます。

本エディションの機能は、Gumroadのサブスクリプション契約に応じて提供されます。


動作環境
--------
- Windows 11 24H2
- インストールのための管理者権限
- インターネット接続(ライセンス管理サービスが約24時間ごとにGumroadへ
  サブスクリプションの有効性を再確認します。直近の確認結果を使って、
  ネットワーク未接続でも最大7日間はオフラインで機能し続けます)


インストール手順
----------------
1. 「Install-kasane.exe」を実行してください。

2. セットアップウィザードの指示に従ってください。キーボードドライバ・
   ライセンス管理サービス(kasaneLicenseSvc)・ライセンス管理ツールが
   インストールされます。

3. デバイス識別方法として、デバイスインスタンスIDモードと、ハードウェアID
   モードのいずれかを選択することが可能です。

　　デフォルトは、デバイスインスタンスIDモードです。この場合、接続先ごとに
　　異なる識別となるので、同じ型式のキーボードを区別することが可能です。

　　ハードウェアIDモードでは、同じ型式のキーボードは区別できず同じと
　　なります。この場合、接続先を変えても同じものだと判断します。

4. インストール完了には再起動が必要です。

5. 再起動後、スタートメニューから「kasane License Manager」が
   自動起動しています。Gumroadで購入したライセンスキーを入力して
   アクティベートしてください。

6. 再度、再起動するか、キーボードを接続しなおすと利用可能となります
   (ドライバはデバイスの(再)接続時に現在のライセンス状態を反映します)。

重要: サブスクリプションライセンスが無効となると、レイヤーリマップ機能が
無効となります。キーボードの基本的な入力機能には影響しません。

アンインストール
----------------
1. 先に kasane を開き、「OFF（素通しに戻す）」を押してください（キーボードを
   本来の動作に戻します）。
2. Windowsの設定「アプリと機能」から「かさね Subscription」を削除します
   （管理者の権限が必要です）。
3. PCを再起動してください。ドライバはキーボードで使用中のため、再起動した
   時点で削除が完了します。再起動するまでは、ドライバが動いたままの場合が
   あります（手順1でOFFにしておけば、キーの割り当ては効きません）。

削除されるもの:
- プログラム（C:\Program Files\applet\kasane）とスタートメニューの項目
- ライセンス管理サービス（kasaneLicenseSvc）
- ドライバ（kbdlayer）と、ドライバに保存されていた設定（キーマップ、
  マクロ、コンボ、タイミング、NICOLA、緊急解除の組み合わせなど）

削除されずに残るもの（再インストールしたときに引き継ぐため）:
- %ProgramData%\kbdlayer-license … ライセンスキーとログ。再インストールすると、
  このライセンスキーで自動的に再確認するので、アクティベートし直す必要は
  ありません（インターネット接続が必要です）。
- %LOCALAPPDATA%\applet\kasane … kasane で保存したキーマップ。再インストール後に
  kasane を開き、「キーボードに適用（ON）」を押すと元の設定に戻ります。
  （以前の名前 LayerDriver の版を使っていた場合は %LOCALAPPDATA%\LayerDriver も
  残っています。）
完全に削除したい場合は、アンインストールと再起動の後に、これらのフォルダを
手で削除してください。

上書きインストール（新しい版をそのままインストール）では、ドライバの設定も
ライセンスもそのまま引き継がれます。アンインストールは不要です。
