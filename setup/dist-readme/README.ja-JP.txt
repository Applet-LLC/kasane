かさね Subscription インストールガイド 1.00 2026-08-19 Applet LLC
================================================================================

このパッケージは、Windowsカーネルモードのキーボードクラスフィルタドライバ
「kbdlayer.sys」をインストールします。QMK/VIA/VIAL形式のキーボードレイヤー
（レイヤー切り替え、Mod-Tap、Layer-Tapなど）をドライバ自身がエミュレートする
ので、リマップ後のレイアウトは、ゲーム中やログイン画面も含めてシステム全体で
働きます。キーボードとWindowsの間に、常駐するユーザーモードのプロセスは挟み
ません。

かさね（kasane）は、同じ作者によるデバイス識別ドライバkbdaddidからフォークされて
おり、デバイスごとの識別の仕組みをそのまま引き継いでいます。複数台のキーボードを
同時に接続していても、特定の1台にだけレイヤーキーマップを適用できます。

本エディションの機能は、Gumroadのサブスクリプション契約に応じて提供されます。


動作環境
--------
- Windows 11 24H2（x64 または ARM64）
- インストールのための管理者権限
- インターネット接続。ライセンス管理サービスが約24時間ごとにGumroadへ接続し、
  サブスクリプションが有効かどうかを再確認します。直近の確認結果を使うので、
  ネットワークに接続できなくても、最大7日間はオフラインのまま使えます。


インストール手順
----------------
1. 「Install-kasane.exe」を実行します。

2. セットアップウィザードの指示に従います。キーボードドライバ、ライセンス管理
   サービス（kasaneLicenseSvc）、ライセンス管理ツールがインストールされます。

   インストール先は C:\Program Files\applet\kasane に固定されており、変更
   できません。トレイのアプリがUI操作（uiAccess）を使うには、署名済みの実行
   ファイルを、管理者しか書き込めないProgram Files配下に置く必要があるためです。
   設定ファイルの保存先は、手順3の設定フォルダで変えられます。

3. 設定フォルダ（任意）。設定ファイル（キーボードごとの設定、トレイの設定、
   ログ）の保存先を、環境変数 KASANE（マシン全体）で指定できます。空欄のままなら、
   従来どおり各ユーザーの %LOCALAPPDATA%\applet\kasane に保存されます。
   Windows 11の管理者保護が有効な環境では、昇格して起動した設定画面が別の
   ユーザーとして動くため、保存先が2か所に分かれることがあります。ここで指定
   すると、保存先を1か所に固定できます。指定したフォルダが無ければ、作成します。

4. 設定ファイルの取り込み（任意。既定はオフ）。kasaneで書き出した設定ファイル
   （*.kasane.json）を、インストール時にドライバへ反映します。管理者保護の
   環境で、インストール後に「キーボードに適用」を実行できない場合に使います。
   すでにドライバに設定がある型番は、取り込んだ内容で置き換わります。前の設定は
   1世代だけ残してあり、設定画面から戻せます。

5. インストールを完了するには、再起動が必要です。

6. 再起動すると、「kasane License Manager」が自動で起動します。Gumroadで購入
   したライセンスキーを入力して、アクティベートしてください。

7. もう一度再起動するか、キーボードを接続しなおすと、使えるようになります。
   ドライバは、デバイスが（再）接続されたときに、そのときのライセンスの状態を
   反映するためです。

タスクトレイ
------------
ログインすると、タスクトレイ（通知領域。隠れているときは「^」の中）に kasane の
アイコンが表示されます。
- 左クリック: kasane（キーマップの編集）を開きます。
- 右クリック: 設定、一時停止、ライセンス、終了のメニューが出ます。
  「一時停止」を押すと、すべてのキーボードのリマップを一時的に止めます（もう一度
  押すと再開します）。
- NICOLA（親指シフト）を設定している場合、IMEがかなモードのときだけ自動で
  NICOLAになります（IME連動）。kasaneの「設定」→「NICOLA」でON/OFFを切り替えられ
  ます。
- ヘルパー動作: キーを押して、プログラムの起動、文字列の入力、マウス操作、
  レイヤーの切り替えなどを実行できます。kasaneのキー割り当て画面の「ヘルパー
  動作」から作ります（トレイが動いている必要があります）。F13〜F24などのキーで
  動かす設定は、「設定」→「ヘルパー動作」にあります。
- アプリ別レイヤー: 前面にあるアプリに合わせて、レイヤーを切り替えたり、リマップ
  を止めたりできます（ゲームなどで使います）。「設定」→「アプリ別レイヤー」に
  あります。
- インポート／エクスポート: kasaneの「インポート／エクスポート...」で、設定を
  ファイル（*.kasane.json）に保存したり、読み込んだりできます。別のキーボードや
  別のパソコンに設定を移せます。のどか（nodoka）の設定ファイルも、変換して
  取り込めます。

サブスクリプションライセンスが無効になると、レイヤーリマップの機能が使えなく
なります。キーボードの基本的な入力は、そのまま使えます。

アンインストール
----------------
1. 先に kasane を開き、「OFF（素通しに戻す）」を押します。キーボードの動作が
   本来の状態に戻ります。
2. Windowsの設定の「アプリと機能」から、「かさね Subscription」を削除します
   （管理者の権限が必要です）。
3. PCを再起動します。ドライバはキーボードで使用中のため、再起動した時点で削除が
   完了します。再起動するまでは、ドライバが動いたままのことがあります（手順1で
   OFFにしておけば、キーの割り当ては効きません）。

削除されるもの:
- プログラム（C:\Program Files\applet\kasane）とスタートメニューの項目
- ライセンス管理サービス（kasaneLicenseSvc）
- ドライバ（kbdlayer）と、ドライバに保存されていた設定（キーマップ、マクロ、
  コンボ、タイミング、NICOLA、緊急解除の組み合わせなど）

削除されずに残るもの（再インストールしたときに引き継ぐため）:
- %ProgramData%\kbdlayer-license … ライセンスキーとログ。再インストールすると、
  このライセンスキーで自動的に再確認するので、アクティベートし直す必要は
  ありません（インターネット接続が必要です）。
- %LOCALAPPDATA%\applet\kasane … kasane で保存したキーマップ。再インストール後に
  kasane を開き、「キーボードに適用（ON）」を押すと、元の設定に戻ります。
  以前の名前 LayerDriver の版を使っていた場合は、%LOCALAPPDATA%\LayerDriver
  も残っています。
完全に削除したい場合は、アンインストールと再起動の後に、これらのフォルダを手で
削除してください。

上書きインストール（新しい版をそのままインストールする方法）では、ドライバの設定
もライセンスも、そのまま引き継がれます。アンインストールは不要です。
